# Chit 15: Handwritten MNIST FNN: two hidden layers

15. Implement a Feedforward Neural Network using two hidden Dense layers to classify handwritten digits. Observe the effect of hidden layers on model performance. Use Dataset -- Handwritten MNIST 

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense


# Step 2: Load and prepare Handwritten MNIST
from tensorflow.keras.datasets import mnist

(X_train, y_train), (X_test, y_test) = mnist.load_data()
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
class_names = [str(i) for i in range(10)]
image_shape = (28, 28, 1)


# Step 3: Flatten the images
X_train = X_train.reshape(len(X_train), 784)
X_test = X_test.reshape(len(X_test), 784)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)


# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")






















# Chit 15: Handwritten MNIST FNN — Two Hidden Layers

## Aim

Build a Feedforward Neural Network (FNN) with **two hidden Dense layers** to classify handwritten digits from 0 to 9. Then measure its accuracy on test images.

## How the model works

```text
28 × 28 digit image → flatten to 784 values → Dense(256) → Dense(128) → Softmax(10 digits)
```

The two hidden layers learn patterns from the image pixels. The final layer chooses one of the ten digit classes.

## Step 1: Import the libraries

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
```

- `numpy as np` imports NumPy. It is not directly used later in this code.
- `tensorflow as tf` imports TensorFlow. `tf` is also not directly used later.
- `Sequential` creates a model with layers arranged in order.
- `Input` defines the shape of each input example.
- `Dense` creates a fully connected neural network layer.

## Step 2: Load and prepare Handwritten MNIST

```python
from tensorflow.keras.datasets import mnist

(X_train, y_train), (X_test, y_test) = mnist.load_data()
```

- `mnist` is the handwritten digit dataset provided by Keras.
- `load_data()` loads the images and their correct labels.
- `X_train` and `y_train` contain the training images and labels.
- `X_test` and `y_test` contain separate test images and labels.

```python
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
```

- `.astype("float32")` converts pixel values to decimal numbers.
- `/ 255.0` scales pixels from 0–255 to 0–1. This is called **normalization**.

```python
class_names = [str(i) for i in range(10)]
image_shape = (28, 28, 1)
```

- `range(10)` produces numbers 0 through 9.
- `str(i)` converts each number to text.
- `class_names` becomes `["0", "1", ..., "9"]`. It is not used later in this code.
- `image_shape` describes a 28 × 28 grayscale image with one channel. It is also not used later.

## Step 3: Flatten the images

```python
X_train = X_train.reshape(len(X_train), 784)
X_test = X_test.reshape(len(X_test), 784)
```

- `len(X_train)` and `len(X_test)` give the number of images in each set.
- `784` is the number of pixels in each 28 × 28 image: `28 × 28 = 784`.
- `.reshape(...)` turns each two-dimensional image into a one-dimensional list of pixel values.
- This is called **flattening**. A Dense layer expects each image as a vector.

## Step 4: Build the model

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

- `num_classes` counts the digit classes: 10.
- `Sequential([...])` arranges the layers in order.
- `Input(shape=(X_train.shape[1],))` tells the model that each image has 784 input values.
- `Dense(256, activation="relu")` is the **first hidden layer**, with 256 neurons.
- `Dense(128, activation="relu")` is the **second hidden layer**, with 128 neurons.
- `activation="relu"` changes negative values to zero and keeps positive values. It allows the model to learn patterns.
- `Dense(num_classes, ...)` creates 10 output neurons, one for each digit.
- `activation="softmax"` turns output scores into probabilities. The digit with the highest probability is the prediction.

## Step 5: Compile the model

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

- `optimizer="adam"` selects the method for updating the model’s weights as it learns.
- `loss="sparse_categorical_crossentropy"` measures how far the predictions are from the correct integer labels.
- `metrics=["accuracy"]` asks Keras to track the fraction of correct predictions.

“Sparse” is used because the digit labels are integers, such as `4`, rather than one-hot vectors.

## Step 6: Train the model

```python
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)
```

- `model.fit(...)` trains the model using the training images and labels.
- `epochs=15` means the model processes the full training set 15 times.
- `batch_size=128` means it processes up to 128 images before updating its weights.
- `verbose=0` hides the training progress messages.

## Step 7: Evaluate on test data

```python
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
```

- `model.evaluate(...)` measures performance on the separate test images.
- It returns loss first and accuracy second.
- `_` receives the loss, which this line does not use.
- `test_accuracy` receives the accuracy.

```python
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")
```

- `print(...)` displays the result.
- `test_accuracy * 100` converts the fraction into a percentage.
- `:.2f` formats it to two decimal places.

## Output interpretation

```text
Testing accuracy: 97.93%
```

The model classified **97.93% of the test images correctly**.

### Step 4: Build the Model

```python
num_classes = len(class_names)

    Input(shape=(X_train.shape[1],)),
```

**1. `num_classes = len(class_names)`**

**2. `Sequential()`**

Creates a neural network with layers arranged sequentially.

**3. Input layer**

```python
Input(shape=(X_train.shape[1],))
```

- Defines the input size.
- `X_train.shape[1]` gives 784.
- Therefore, the model accepts 784 input values.

**4. First hidden layer**

```python
Dense(256, activation="relu")
```

- Contains 256 neurons.
- Uses ReLU activation function.
- Learns patterns and features from the input pixels.

**5. Second hidden layer**

```python
Dense(128, activation="relu")
```

- Contains 128 neurons.
- Uses ReLU activation.
- Learns more complex patterns from the features extracted by the first hidden layer.

**6. Output layer**


- Contains 10 neurons because there are 10 digit classes.

**What is the effect of using two hidden layers?**

- Hidden layers help the model learn patterns from handwritten images.

### Step 5: Compile and Train

**Compile the model:**

```python
model.compile(
    optimizer="adam",

    metrics=["accuracy"]

```

Compilation configures the model for training.

| Parameter | Explanation |
|---|---|
| `optimizer="adam"` | Updates the model weights to reduce errors during training. |
| `loss="sparse_categorical_crossentropy"` | Measures the difference between actual and predicted classes. |
| `metrics=["accuracy"]` | Measures how many predictions are correct. |

**Why sparse categorical crossentropy?**

Because the output has multiple classes (0–9), and the labels are provided as integer values rather than one-hot encoded vectors.

**Train the model:**

```python

```

- `model.fit()` trains the neural network.
- `X_train` contains training images.
- `y_train` contains their actual labels.
- `epochs=15`: The model goes through the complete training dataset 15 times.
- `batch_size=128`: The model processes 128 images in one batch before updating its weights.
- `verbose=0`: Does not display training progress.

**What is an epoch?**

One complete pass through the entire training dataset is called an epoch.

**What is batch size?**

The number of training samples processed before updating the model's weights is called batch size.

## 4. Important Viva Questions and Answers

### Q1. What is MNIST?
MNIST stands for Modified National Institute of Standards and Technology. It is a dataset of handwritten digits from 0 to 9.

### Q2. How many images are present in MNIST?
It contains 70,000 images:
- 60,000 training images.
- 10,000 testing images.

### Q3. What is the size of MNIST images?
Each image is 28 × 28 pixels.

### Q4. How many classes are present in MNIST?
There are 10 classes, representing digits 0 to 9.

### Q5. What is an FNN?
FNN stands for Feedforward Neural Network. In this network, information moves from the input layer towards the output layer without moving backward.

### Q6. What is a hidden layer?
A hidden layer is a layer between the input and output layers that learns patterns and features from the input data.

### Q7. How many hidden layers are used in this practical?
Two hidden Dense layers are used:
- First hidden layer: 256 neurons.
- Second hidden layer: 128 neurons.

### Q8. Why are two hidden layers used?
They help the model learn more complex patterns and features from handwritten digit images.

### Q9. What is a Dense layer?
A Dense layer is a fully connected layer in which every neuron is connected to all neurons in the previous layer.

### Q10. What is ReLU?
ReLU stands for Rectified Linear Unit. It converts negative values into zero and keeps positive values unchanged.

Formula:

`ReLU(x) = max(0, x)`

### Q11. What is Softmax?
Softmax is an activation function that converts output values into probabilities. The class with the highest probability is selected.

### Q12. Why do we use 10 neurons in the output layer?
Because MNIST contains 10 digit classes, from 0 to 9.

### Q13. Why do we flatten the images?
We flatten images from 28 × 28 into 784 values because an FNN requires one-dimensional input.

### Q14. Why do we divide pixel values by 255?
To normalize pixel values from the range 0–255 to the range 0–1.

### Q15. What is Adam optimizer?
Adam is an optimization algorithm that updates the weights and biases of a neural network to reduce prediction errors.

### Q16. What is loss?
Loss measures the difference between the actual output and the predicted output.

### Q17. What is accuracy?
Accuracy is the percentage of correctly classified images out of the total images.

### Q18. What is the difference between FNN and CNN?
- FNN uses flattened input and fully connected layers.
- CNN uses convolution and pooling layers to extract spatial features from images.

### Q19. What is the effect of increasing hidden layers?
Increasing hidden layers can help the model learn more complex patterns. However, too many layers can increase training time and cause overfitting.

### Q20. What is overfitting?
Overfitting occurs when a model performs very well on training data but performs poorly on unseen testing data.

### Q21. What is the difference between training and testing data?
- Training data is used to teach the model.
- Testing data is used to evaluate the trained model's performance.

### Q22. What does 97.93% testing accuracy indicate?
It indicates that the model correctly classifies approximately 97.93% of the test images.
