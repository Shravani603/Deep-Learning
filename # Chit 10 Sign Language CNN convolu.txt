# Chit 10: Sign Language CNN: convolutional feature extraction

10. Implement a CNN to extract features from grayscale hand gesture images using convolution and max-pooling layers. Use the extracted features for alphabet classification and display the test accuracy.

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
from sklearn.preprocessing import LabelEncoder


# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Reshape the images
X_train = X_train.reshape(-1, 28, 28, 1)
X_test = X_test.reshape(-1, 28, 28, 1)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)


# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")























# Chit 10: Sign Language CNN — Convolutional Feature Extraction

## Aim

Use a CNN to learn visual features from grayscale hand gesture images, classify them into alphabet classes, and report accuracy on the test data.

## CNN flow

```text
28 × 28 grayscale image
       ↓
Conv2D → MaxPooling2D → Conv2D → MaxPooling2D
       ↓
Flatten → Dense(128) → Softmax(24 classes)
```

The convolution layers learn image features, such as edges and shapes. The Dense layers use those features to predict the letter.

## Step 1: Import the libraries

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
from sklearn.preprocessing import LabelEncoder
```

- `pandas as pd` reads the CSV files.
- `LabelEncoder` converts labels into consecutive numbers.
- `Sequential` creates a model whose layers run in order.
- `Input` defines the shape of each input image.
- `Conv2D` learns visual patterns from image regions.
- `MaxPooling2D` reduces the size of the feature maps.
- `Flatten` turns the feature maps into a one-dimensional list.
- `Dense` creates fully connected layers.
- `numpy as np` and `tensorflow as tf` are imported but not directly used in this code.

## Step 2: Load and prepare Sign Language MNIST

```python
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")
```

- `pd.read_csv(...)` loads a CSV file into a table.
- `train_df` contains the examples used to train the model.
- `test_df` contains separate examples used to evaluate it.

```python
X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
```

These lines prepare the image pixels:

- `X_train` and `X_test` hold the input images. `X` is a common name for inputs.
- `.drop(columns="label")` removes the answer column, leaving the pixels.
- `.to_numpy(dtype="float32")` converts the pixels into decimal numbers.
- `/ 255.0` scales pixel values from 0–255 to 0–1. This is called **normalization**.

```python
encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)
```

- `LabelEncoder()` creates a label converter.
- `fit_transform(...)` learns the mapping from the training labels and converts them into consecutive numbers.
- `transform(...)` applies the same mapping to the test labels.
- `y_train` and `y_test` contain the correct class numbers for each image.
- `class_names` converts original label numbers into letters. It is only used here to find the number of classes.
- `image_shape` describes a 28 × 28 grayscale image with one channel. This variable is not used later in this practical.

There are 24 classes in Sign Language MNIST. The J and Z gestures are omitted because they involve movement.

## Step 3: Reshape the images

```python
X_train = X_train.reshape(-1, 28, 28, 1)
X_test = X_test.reshape(-1, 28, 28, 1)
```

A CNN expects each image to have height, width, and channel dimensions.

- `28, 28` is the image height and width.
- `1` means the image has one grayscale channel.
- `-1` tells Python to work out the number of images automatically.

The resulting shape is:

```text
(number of images, 28, 28, 1)
```

## Step 4: Build the model

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

- `num_classes = len(class_names)` counts the classes. Here, it is 24.
- `Sequential([...])` places the model’s layers in order.
- `Input(shape=X_train.shape[1:])` sets the image shape to `(28, 28, 1)`. It leaves out the number-of-images dimension.
- `Conv2D(32, (3, 3), ...)` learns 32 filters. Each filter looks at a 3 × 3 region at a time.
- `MaxPooling2D((2, 2))` reduces the feature-map size by selecting the largest value in each 2 × 2 region.
- The second `Conv2D` learns 64 filters that can detect more complex patterns.
- The second `MaxPooling2D` reduces the maps again.
- `Flatten()` converts the feature maps into a one-dimensional list.
- `Dense(128, ...)` combines the extracted features using 128 neurons.
- `Dense(num_classes, ...)` produces an output for each of the 24 gesture classes.
- `activation="relu"` sets negative values to zero and keeps positive values.
- `activation="softmax"` turns the output scores into probabilities across the classes.

The feature-map sizes are approximately:

```text
28 × 28 × 1
→ 26 × 26 × 32
→ 13 × 13 × 32
→ 11 × 11 × 64
→ 5 × 5 × 64
→ Flatten → 1,600 values
```

## Step 5: Compile the model

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

- `optimizer="adam"` selects how the model updates its weights while learning.
- `loss="sparse_categorical_crossentropy"` measures how far the predictions are from the correct integer labels.
- `metrics=["accuracy"]` asks Keras to track the fraction of correct predictions.

“Sparse” is appropriate because the labels are stored as class numbers, rather than one-hot vectors.

## Step 6: Train the model

```python
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)
```

- `model.fit(...)` trains the model on the training images and labels.
- `epochs=10` means the model goes through the training data 10 times.
- `batch_size=128` means it processes up to 128 images before updating its weights.
- `verbose=0` hides the training progress messages.

## Step 7: Evaluate on test data

```python
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
```

- `model.evaluate(...)` checks performance using the test images and their correct labels.
- It returns the loss and accuracy, in that order.
- `_` receives the loss, which this line does not use.
- `test_accuracy` receives the accuracy result.
- `verbose=0` hides the evaluation progress messages.

```python
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")
```

- `print(...)` displays the result.
- `test_accuracy * 100` converts the accuracy from a fraction to a percentage.
- `:.2f` formats it to two decimal places.

## Output interpretation

```text
Testing accuracy: 90.94%
```

The model classified **90.94% of the test images correctly**. Test accuracy measures performance on examples separate from those used to train the model.

```python
    Flatten(),

])
```

This creates the CNN architecture.

**Layer-by-layer explanation:**

| Layer | Explanation |
|---|---|
| `Input(shape=X_train.shape[1:])` | Defines the input image shape as 28 × 28 × 1. |
| `Conv2D(32, (3,3), activation="relu")` | Uses 32 filters of size 3 × 3 to extract basic image features. |
| `MaxPooling2D((2,2))` | Reduces feature map dimensions. |
| `Conv2D(64, (3,3), activation="relu")` | Uses 64 filters to extract more complex features. |
| `MaxPooling2D((2,2))` | Further reduces feature map dimensions. |
| `Flatten()` | Converts feature maps into a 1D array. |
| `Dense(128, activation="relu")` | Fully connected layer with 128 neurons. |
| `Dense(num_classes, activation="softmax")` | Output layer that predicts one of the 24 alphabet classes. |

#### Important: How does convolutional feature extraction work?

This is the main concept of this practical.

**1. Convolution Layer**

- Applies filters to the input image.
- Detects basic features such as edges, lines and shapes.
- The second convolution layer learns more complex patterns from the extracted features.

**2. Max Pooling Layer**

- Reduces the size of feature maps.
- Selects the maximum value from a particular region.
- Retains important information while reducing computation.

**3. Flatten Layer**

- Converts extracted feature maps into a one-dimensional vector.
- Passes this information to the Dense layer for classification.

**4. Dense Layer**

- Learns patterns from extracted features.
- Predicts the alphabet class.

**Simple working flow:**

```text
Input Hand Gesture Image
          ↓
   Convolution Layer
          ↓
   Max Pooling Layer
          ↓
   Convolution Layer
          ↓
   Max Pooling Layer
          ↓
      Flatten
          ↓
     Dense Layer
          ↓
    Softmax Output
          ↓
   Predicted Alphabet
```
