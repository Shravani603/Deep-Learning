# Chit 29: CBOW with two words on each side

29. Construct a Continuous Bag of Words model using Python by considering a context window of two words on either side of the target word. Generate training samples, train an embedding-based neural network and predict the target word from the given context. 




# Step 1: Prepare a text corpus
import re
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Embedding, GlobalAveragePooling1D, Dense

with open("document3.txt", encoding="utf-8") as file:
    text = file.read()

text = re.sub(r"[^a-z\s]", " ", text.lower())
words = text.split()
vocabulary = sorted(set(words))
word_to_id = {word: i for i, word in enumerate(vocabulary)}
id_to_word = {i: word for word, i in word_to_id.items()}
print("Vocabulary:", vocabulary)


# Step 2: Make context and target pairs
window_size = 2
contexts, targets = [], []
for i in range(window_size, len(words) - window_size):
    context_words = words[i-window_size:i] + words[i+1:i+window_size+1]
    contexts.append([word_to_id[word] for word in context_words])
    targets.append(word_to_id[words[i]])

X = np.array(contexts, dtype="int32")
y = np.array(targets, dtype="int32")
for i in range(min(5, len(X))):
    print([id_to_word[index] for index in X[i]], "->", id_to_word[y[i]])


# Step 3: Train the CBOW network
embedding_size = 16
model = Sequential([
    Input(shape=(2 * window_size,)),
    Embedding(input_dim=len(vocabulary), output_dim=embedding_size),
    GlobalAveragePooling1D(),
    Dense(len(vocabulary), activation="softmax")
])
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
history = model.fit(X, y, epochs=100, verbose=0)
print("Final training loss:", round(history.history["loss"][-1], 4))


# Step 4: Predict a target word
sample_context = X[0]
prediction = model.predict(sample_context.reshape(1, -1), verbose=0)
predicted_word = id_to_word[int(np.argmax(prediction[0]))]
print("Context:", [id_to_word[index] for index in sample_context])
print("Predicted target:", predicted_word)























# Chit 29: CBOW with Two Words on Each Side

## Aim

Create a Continuous Bag of Words (CBOW) model that predicts a target word from two surrounding words on each side. The model learns word embeddings from `document3.txt`.

## How CBOW works

For a target word, the code takes two words before it and two words after it as context:

```text
the speed [target] is of  →  predict the middle word
```

It converts the four context words into embeddings, averages them, and predicts a word from the vocabulary.

## Step 1: Prepare a text corpus

```python
import re
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Embedding, GlobalAveragePooling1D, Dense
```

- `re` provides regular expressions for cleaning text.
- `numpy as np` creates the arrays used for training and selects the predicted word.
- `Sequential` builds a model with layers in order.
- `Input` sets the model input shape.
- `Embedding` learns vector representations for words.
- `GlobalAveragePooling1D` averages the context word vectors.
- `Dense` creates the layer that predicts the target word.

```python
with open("document3.txt", encoding="utf-8") as file:
    text = file.read()
```

- `open(...)` opens the text file.
- `encoding="utf-8"` tells Python how to read its characters.
- `with` closes the file automatically after reading.
- `file.read()` loads the whole document into `text`.

```python
text = re.sub(r"[^a-z\s]", " ", text.lower())
```

- `text.lower()` converts all letters to lowercase.
- `re.sub(pattern, replacement, text)` replaces matching characters.
- `r"..."` marks the pattern as a raw string.
- `[^a-z\s]` matches anything that is not a lowercase letter or whitespace.
- Matching characters, including punctuation and digits, become spaces.

```python
words = text.split()
```

Splits the cleaned text into individual word tokens using whitespace.

```python
vocabulary = sorted(set(words))
```

- `set(words)` keeps one copy of each unique word.
- `sorted(...)` puts the unique words in alphabetical order.
- `vocabulary` is the list of words the model can predict.

```python
word_to_id = {word: i for i, word in enumerate(vocabulary)}
id_to_word = {i: word for word, i in word_to_id.items()}
print("Vocabulary:", vocabulary)
```

- `enumerate(vocabulary)` pairs each word with an index starting at 0.
- `word_to_id` maps words to numbers.
- `id_to_word` maps numbers back to words.
- `print(...)` displays the vocabulary.

## Step 2: Make context and target pairs

```python
window_size = 2
contexts, targets = [], []
```

- `window_size = 2` sets two context words on each side of the target.
- `contexts` will store the surrounding word indices.
- `targets` will store the target word indices.

```python
for i in range(window_size, len(words) - window_size):
```

Moves through words that have two words before and after them. The first and last two tokens are skipped because they do not have a full context window.

```python
    context_words = words[i-window_size:i] + words[i+1:i+window_size+1]
```

Builds four context words, leaving out the word at position `i`:

- `words[i-window_size:i]` selects the two words before the target.
- `words[i+1:i+window_size+1]` selects the two words after it.
- `+` joins the two lists.

```python
    contexts.append([word_to_id[word] for word in context_words])
    targets.append(word_to_id[words[i]])
```

- The list comprehension converts each context word into its vocabulary index.
- `contexts.append(...)` saves those four indices.
- `word_to_id[words[i]]` gets the target word’s index.
- `targets.append(...)` saves it as the correct answer.

```python
X = np.array(contexts, dtype="int32")
y = np.array(targets, dtype="int32")
```

- `X` contains context indices.
- `y` contains target indices.
- `dtype="int32"` stores the indices as 32-bit integers.

```python
for i in range(min(5, len(X))):
    print([id_to_word[index] for index in X[i]], "->", id_to_word[y[i]])
```

Prints up to five training examples:

- `X[i]` selects a context.
- `id_to_word[index]` converts each context number back into a word.
- `y[i]` selects the target index.
- The arrow shows the context-to-target relationship.

For example:

```text
['the', 'speed', 'transmission', 'is'] -> of
```

The context surrounds the target word `of` in the text.

## Step 3: Train the CBOW network

```python
embedding_size = 16
```

Sets the length of each learned word vector to 16 numbers.

```python
model = Sequential([
    Input(shape=(2 * window_size,)),
    Embedding(input_dim=len(vocabulary), output_dim=embedding_size),
    GlobalAveragePooling1D(),
    Dense(len(vocabulary), activation="softmax")
])
```

- `Input(shape=(2 * window_size,))` sets the input length to four indices: two context words on each side.
- `Embedding(...)` looks up a 16-number vector for each context word.
  - `input_dim=len(vocabulary)` is the number of unique words.
  - `output_dim=embedding_size` is the embedding length, 16.
- `GlobalAveragePooling1D()` averages the four context embeddings into one vector.
- `Dense(len(vocabulary), ...)` creates one output score for every vocabulary word.
- `activation="softmax"` converts those scores into probabilities over the vocabulary.

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

- `optimizer="adam"` selects how the model updates its weights.
- `loss="sparse_categorical_crossentropy"` measures prediction error using integer target indices.
- `metrics=["accuracy"]` asks Keras to track how often the predicted word matches the target.

```python
history = model.fit(X, y, epochs=100, verbose=0)
```

- `model.fit(X, y, ...)` trains on context-target pairs.
- `epochs=100` means the model goes through the training pairs 100 times.
- `verbose=0` hides progress messages.
- `history` stores training metrics, including loss, for each epoch.

```python
print("Final training loss:", round(history.history["loss"][-1], 4))
```

- `history.history["loss"]` is the list of loss values recorded during training.
- `[-1]` selects the final epoch’s loss.
- `round(..., 4)` rounds it to four decimal places.
- `print(...)` displays the result.

## Step 4: Predict a target word

```python
sample_context = X[0]
```

Selects the first context from the training data.

```python
prediction = model.predict(sample_context.reshape(1, -1), verbose=0)
```

- `.reshape(1, -1)` adds a batch dimension so the model receives one context of four word indices.
- `model.predict(...)` returns probabilities for each vocabulary word.
- `verbose=0` hides prediction progress.

```python
predicted_word = id_to_word[int(np.argmax(prediction[0]))]
```

- `prediction[0]` selects the probability vector for this context.
- `np.argmax(...)` finds the index with the highest probability.
- `id_to_word[...]` converts that index back into a word.

```python
print("Context:", [id_to_word[index] for index in sample_context])
print("Predicted target:", predicted_word)
```

Displays the context words and the predicted target word.

## Output interpretation

```text
Final training loss: 2.95

Context: ['the', 'speed', 'transmission', 'is']

```

The model predicts **“of”** for the context `the speed transmission is`. This is the first context from the training data, so the model has already seen this example during training. The output demonstrates the prediction process; it does not test performance on unseen text.

# 2. Understanding CBOW

### What is CBOW?

CBOW stands for **Continuous Bag of Words**.

It is a Word2Vec model used in Natural Language Processing (NLP) to predict a target word using its surrounding context words.

In simple words:

**CBOW takes surrounding words as input and predicts the missing middle word.**

### Example

Consider this sentence:

"The speed of transmission is an important point."

Suppose the target word is **"of"**.

With a context window of two words on each side:

| Position | Word |
|---|---|
| Left context 1 | the |
| Left context 2 | speed |
| Target word | of |
| Right context 1 | transmission |
| Right context 2 | is |

Therefore:

**Input:** the, speed, transmission, is

**Output:** of

### CBOW Architecture

```text
       Context Words
             |
     -----------------
     |   |   |   |
    the speed transmission is
     |   |   |   |
     -----------------
             |
             v
       Embedding Layer
             |
             v
    Global Average Pooling
             |
             v
        Dense Layer
             |
             v
          Softmax
             |
             v
       Predicted Word
            "of"
```

Because the first two words do not have two words before them.

Why does it stop before `len(words)-2`?

This selects two words before and two words after the current target word.

## Step 3: Train the CBOW Neural Network

```python
embedding_size = 16
```

Defines the size of the word embedding vector.

Each word is represented by a vector containing 16 numerical values.

### Create the model

```python
model = Sequential([
    Input(shape=(2 * window_size,)),
    Embedding(input_dim=len(vocabulary), output_dim=embedding_size),
    GlobalAveragePooling1D(),
    Dense(len(vocabulary), activation="softmax")
])
```

Let's understand each layer.

### 1. Input Layer

```python
Input(shape=(2 * window_size,))
```

Defines the input size.

Since the window size is 2:

```text
2 × 2 = 4
```

Therefore, the model accepts four context word indexes.

### 2. Embedding Layer

```python
Embedding(input_dim=len(vocabulary), output_dim=embedding_size)
```

Converts numerical word indexes into dense word vectors.

Parameters:

| Parameter | Meaning |
|---|---|
| `input_dim` | Total number of unique words in vocabulary |
| `output_dim` | Number of values in each embedding vector (16) |

For example:

```text
Word index → Embedding vector

the → [0.12, 0.34, 0.21, ...]
speed → [0.42, 0.18, 0.53, ...]
```

These vectors are learned during training.

### 3. GlobalAveragePooling1D

```python
GlobalAveragePooling1D()
```

Calculates the average of the embedding vectors of all four context words.

**Example:**

Suppose the four context words have embedding vectors:

```text
Word 1 → [1, 2]
Word 2 → [3, 4]
Word 3 → [5, 6]
Word 4 → [7, 8]
```

Average:

```text
[4, 5]
```

This produces one combined context representation.

**Why is it used?**

CBOW uses the surrounding words together to understand the context and predict the target word.

### 4. Dense Output Layer

```python
Dense(len(vocabulary), activation="softmax")
```

- Creates one output neuron for every word in the vocabulary.
- Softmax converts the output values into probabilities.
- The word with the highest probability is selected as the predicted target.

### Compile the model

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

| Parameter | Meaning |
|---|---|
| `optimizer="adam"` | Updates model weights during training |
| `loss="sparse_categorical_crossentropy"` | Measures prediction error when target labels are integer indexes |
| `metrics=["accuracy"]` | Measures the percentage of correct predictions |

**Why sparse categorical crossentropy?**

Because target words are stored as integer indexes, not one-hot encoded vectors.

### Train the model

```python
history = model.fit(X, y, epochs=100, verbose=0)
```

- `X`: Context word indexes.
- `y`: Target word indexes.
- `epochs=100`: The model processes the training samples 100 times.
- `verbose=0`: Hides training progress.
- `history`: Stores training information such as loss and accuracy.

### Display final training loss

```python
print("Final training loss:", round(history.history["loss"][-1], 4))
```

Explanation:

- `history.history["loss"]`: Contains loss values from every epoch.
- `[-1]`: Selects the loss of the final epoch.
- `round(..., 4)`: Rounds the value to four decimal places.

Your output:

```text

```

**What is loss?**

Loss measures how far the model's predictions are from the correct target words.

Generally, lower loss indicates better learning on the training data.
