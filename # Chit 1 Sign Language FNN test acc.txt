# Chit 1: Sign Language FNN: test accuracy

1. Develop a Feedforward Neural Network using TensorFlow/Keras to classify American Sign Language alphabet gestures using the Sign Language MNIST dataset. Normalize the pixel values, flatten the images, train the model using Dense layers and display the test accuracy. 


# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from sklearn.preprocessing import LabelEncoder

# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

print("Training Dataset Shape:", train_df.shape)
print("Testing Dataset Shape:", test_df.shape)

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)

# Step 3: Flatten the images
X_train = X_train.reshape(-1, 28, 28).reshape(-1, 784)
X_test = X_test.reshape(-1, 28, 28).reshape(-1, 784)

# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])

# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)

# Display model architecture
model.summary()

# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)

# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")

# 2. First Understand the Basic Concepts

Before understanding the code, let's understand some important terms.

### Q1. What is Deep Learning?

Deep Learning is a part of Machine Learning that uses artificial neural networks to learn from data and make predictions.

Example: Recognizing handwritten digits, identifying objects and recognizing sign language.

### Q2. What is a Feedforward Neural Network (FNN)?

A Feedforward Neural Network is an artificial neural network in which information moves in only one direction:

**Input Layer → Hidden Layers → Output Layer**

- Input Layer: Accepts the input data.
- Hidden Layers: Learn patterns from the input.
- Output Layer: Produces the final prediction.

There are no feedback connections or loops.

### Q3. What is Sign Language MNIST?

Sign Language MNIST is a dataset containing images of American Sign Language hand gestures.

- Image size: 28 × 28 pixels.
- Each image represents a hand gesture.
- Used for alphabet gesture classification.
- Contains 24 classes.

**Important:** The dataset contains 24 classes because the letters J and Z require movement, which cannot be represented properly using a single static image.

### Q4. What is TensorFlow?

TensorFlow is an open-source library developed by Google for Machine Learning and Deep Learning.

It helps us build, train and evaluate neural networks.

### Q5. What is Keras?

Keras is a high-level Deep Learning API used to build neural networks easily.

It provides functions such as:
- Sequential()
- Dense()
- compile()
- fit()
- evaluate()

`reshape()` changes the shape of an array without changing its actual data.

In:


Converts each 28 × 28 image into a 784-element vector.

Why 784?

Because:

**Important viva point:**

### What is ReLU?

ReLU is an activation function that converts negative values into zero and keeps positive values unchanged.

Formula:

```text
f(x) = max(0, x)
```

Example:

| Input | ReLU Output |
|---:|---:|
| -5 | 0 |
| -2 | 0 |
| 0 | 0 |
| 3 | 3 |
| 8 | 8 |

**Why do we use ReLU?**

It introduces non-linearity into the neural network and helps it learn complex patterns.

**Layer 3: Second Hidden Layer**

```python
Dense(128, activation="relu")
```

- Dense layer with 128 neurons.
- Uses ReLU activation.
- Learns additional patterns from the previous layer.

**Layer 4: Output Layer**

```python
Dense(num_classes, activation="softmax")
```

Since:

```text
num_classes = 24
```

The output layer contains 24 neurons.

### What is Softmax?

Softmax is an activation function that converts output values into probabilities.

For example:

```text
A = 0.10
B = 0.70
C = 0.05
D = 0.15
```

The model predicts the class with the highest probability.

Here, B is predicted because it has the highest probability.

**Why do we use Softmax?**

Because this is a multi-class classification problem, where the model must select one class from 24 possible classes.

Loss function measures the difference between the actual output and predicted output.

- We have multiple classes.
- Target labels are represented as integers.

Example:

```text

```

The loss function measures how incorrect the prediction is.

**Why sparse categorical crossentropy?**

Because our dataset contains 24 classes and the labels are integer encoded, not one-hot encoded.

### 3. `metrics=["accuracy"]`

Accuracy measures how many predictions are correct.

Formula:

Accuracy = (Correct Predictions / Total Predictions) × 100

Example:

If 80 predictions are correct out of 100:

Accuracy = 80%.
