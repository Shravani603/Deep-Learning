# Chit 7: Sign Language CNN: five predicted alphabet labels

7. Implement a CNN model to recognize different alphabet hand gestures. Use Conv2D, MaxPooling2D, Flatten and Dense layers. Evaluate the model using test data and display predicted alphabet labels for five test images. 

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
from sklearn.preprocessing import LabelEncoder
import matplotlib.pyplot as plt


# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Reshape the images
X_train = X_train.reshape(-1, 28, 28, 1)
X_test = X_test.reshape(-1, 28, 28, 1)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)


# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")


# Step 8: Predict test images
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)


# Step 9: Show five examples
plt.figure(figsize=(14, 4))
for i in range(5):
    image = X_test[i].reshape(image_shape)
    plt.subplot(1, 5, i + 1)
    if image_shape[-1] == 1:
        plt.imshow(image.squeeze(), cmap="gray")
    else:
        plt.imshow(image)
    plt.title(f"Actual: {class_names[int(y_test[i])]}\nPredicted: {class_names[int(y_pred[i])]}")
    plt.axis("off")
plt.tight_layout()
plt.show()

### Next Code

- 128 becomes approximately 0.50.
- 255 becomes 1.

This helps the model learn efficiently.

- `LabelEncoder()` creates a label encoder.
- `fit_transform()` learns the training labels and converts them into numerical values.
- `transform()` converts testing labels using the same mapping.

**Why do we use LabelEncoder?**

To convert alphabet labels into numerical values that the CNN model can understand.

### Next Code

class_names = [chr(int(label) + 65) for label in encoder.classes_]

- `encoder.classes_` – Returns the original available classes.

- `chr()` – Converts ASCII value into an alphabet.

## Step 4: Build the CNN Model

### Code

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

This step creates the CNN architecture.

Let's understand each layer.

### 1. Input Layer

```python
Input(shape=X_train.shape[1:])
```

- Accepts input images.
- Image dimensions are 28 × 28 × 1.
- `shape[1:]` selects image dimensions without the number of images.

### 2. First Convolutional Layer

```python
Conv2D(32, (3, 3), activation="relu")
```

- `Conv2D` – Performs convolution.
- `32` – Number of filters.
- `(3,3)` – Kernel size.
- `relu` – Activation function.

It extracts basic image features such as edges and shapes.

### 3. First Max Pooling Layer

```python
MaxPooling2D((2, 2))
```

Reduces feature map dimensions by selecting the maximum value from each 2 × 2 region.

### 4. Second Convolutional Layer

```python
Conv2D(64, (3, 3), activation="relu")
```

Uses 64 filters to extract more detailed features from images.

### 5. Second Max Pooling Layer

```python
MaxPooling2D((2, 2))
```

Further reduces feature map dimensions and retains important features.

### 6. Flatten Layer

```python
Flatten()
```

Converts multidimensional feature maps into a one-dimensional array.

### 7. Dense Layer

```python
Dense(128, activation="relu")
```

Creates a fully connected layer with 128 neurons.

It learns relationships between extracted features.

### 8. Output Layer

```python
Dense(num_classes, activation="softmax")
```

- Creates 24 output neurons.
- Softmax calculates the probability of each alphabet.
- The alphabet with the highest probability is selected.

### Remember the CNN Architecture

```text
       Input Image
       28 × 28 × 1
             |
             v
       Conv2D (32)
          3 × 3
           ReLU
             |
             v
      MaxPooling (2 × 2)
             |
             v
       Conv2D (64)
          3 × 3
           ReLU
             |
             v
      MaxPooling (2 × 2)
             |
             v
          Flatten
             |
             v
       Dense (128)
           ReLU
             |
             v
       Dense (24)
          Softmax
             |
             v
     Predicted Alphabet
```

Stores the predicted numerical labels of all testing images.

**Remember:**

`model.predict()` predicts the output, whereas `np.argmax()` selects the class having the highest probability.
