# Step 1: Load the ECG data
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense

data = pd.read_csv("ecg.csv", header=None)
X = data.iloc[:, :-1].to_numpy(dtype="float32")
labels = data.iloc[:, -1].to_numpy()
normal_label = pd.Series(labels).value_counts().idxmax()
print("Most common class (assumed normal):", normal_label)

normal = X[labels == normal_label]
abnormal = X[labels != normal_label]
X_train, X_val = train_test_split(normal, test_size=0.2, random_state=42)


# Step 2: Scale the ECG features
scaler = MinMaxScaler()
X_train = scaler.fit_transform(X_train)
X_val = scaler.transform(X_val)
X_test = np.vstack([X_val, scaler.transform(abnormal)])
y_test = np.concatenate([np.zeros(len(X_val), dtype=int), np.ones(len(abnormal), dtype=int)])


# Step 3: Build and train the autoencoder
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(32, activation="relu"),
    Dense(16, activation="relu"),
    Dense(32, activation="relu"),
    Dense(X_train.shape[1], activation="linear")
])
model.compile(optimizer="adam", loss="mse")
model.summary()
history = model.fit(X_train, X_train, epochs=10, batch_size=128, validation_split=0.1, verbose=0)


# Step 4: Detect abnormal records
val_reconstruction = model.predict(X_val, verbose=0)
val_errors = np.mean(np.square(X_val - val_reconstruction), axis=1)
threshold = np.percentile(val_errors, 95)

test_reconstruction = model.predict(X_test, verbose=0)
test_errors = np.mean(np.square(X_test - test_reconstruction), axis=1)
y_pred = (test_errors > threshold).astype(int)
print("Reconstruction-error threshold:", threshold)
print("Actual abnormal records in test:", int(y_test.sum()))
print("Detected abnormal records:", int(y_pred.sum()))


# Step 5: Plot sample signals and errors
normal_i = 0
abnormal_indices = np.where(y_test == 1)[0]
abnormal_i = int(abnormal_indices[0]) if len(abnormal_indices) else normal_i

plt.figure(figsize=(12, 4))
plt.plot(X_test[normal_i], label="Original normal")
plt.plot(test_reconstruction[normal_i], label="Reconstructed")
plt.title("Normal ECG reconstruction")
plt.legend()
plt.show()

if len(abnormal_indices):
    plt.figure(figsize=(12, 4))
    plt.plot(X_test[abnormal_i], label="Original abnormal")
    plt.plot(test_reconstruction[abnormal_i], label="Reconstructed")
    plt.title("Abnormal ECG reconstruction")
    plt.legend()
    plt.show()

plt.figure(figsize=(10, 4))
plt.hist(test_errors, bins=40)
plt.axvline(threshold, color="red", linestyle="--", label="Threshold")
plt.xlabel("Reconstruction error")
plt.ylabel("Number of records")
plt.legend()
plt.show()




















# Chit 32: ECG Anomaly Detection with an Autoencoder

## Aim

Train an autoencoder mainly on normal ECG records so it learns to reconstruct normal patterns. Then use reconstruction error to flag records that differ from those patterns.

```text
ECG record → Encoder → compressed representation → Decoder → reconstructed record
                                      ↓
                          compare original and reconstructed
                                      ↓
                           large error → flag as anomaly
```

## Step 1: Load the ECG data

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
```

- `numpy` and `pandas` handle arrays and tabular data.
- `matplotlib.pyplot` plots the ECG signals and error histogram.
- `train_test_split` separates normal records into training and validation sets.
- `MinMaxScaler` scales feature values to a consistent range.
- `Sequential`, `Input`, and `Dense` build the autoencoder.

```python
data = pd.read_csv("ecg.csv", header=None)
X = data.iloc[:, :-1].to_numpy(dtype="float32")
labels = data.iloc[:, -1].to_numpy()
```

- `pd.read_csv(...)` reads the CSV file.
- `header=None` tells Pandas the file has no header row.
- `data.iloc[:, :-1]` selects every row and every column except the last.
- `X` contains the ECG features or samples.
- `data.iloc[:, -1]` selects the final column, assumed to contain the class label.
- `labels` stores the record labels.

```python
normal_label = pd.Series(labels).value_counts().idxmax()
print("Most common class (assumed normal):", normal_label)
```

- `pd.Series(labels)` makes the labels into a Pandas Series.
- `.value_counts()` counts how often each class appears.
- `.idxmax()` returns the label with the largest count.
- The code assumes that the most common class is normal.

Your output says:

```text
Most common class (assumed normal): 1.0
```

So this code treats label `1.0` as the normal class. That is an assumption based on frequency; it is only valid if the dataset’s label definitions confirm it.

```python
normal = X[labels == normal_label]
abnormal = X[labels != normal_label]
X_train, X_val = train_test_split(normal, test_size=0.2, random_state=42)
```

- `labels == normal_label` creates a True/False selection for records labelled normal.
- `normal` contains the assumed normal records.
- `labels != normal_label` selects every other label.
- `abnormal` contains the records treated as abnormal.
- `train_test_split(...)` separates normal records into training and validation sets.
- `test_size=0.2` puts 20% of normal records in `X_val`.
- `random_state=42` makes this split repeatable.

## Step 2: Scale the ECG features

```python
scaler = MinMaxScaler()
X_train = scaler.fit_transform(X_train)
X_val = scaler.transform(X_val)
```

- `MinMaxScaler()` creates a scaler.
- `fit_transform(X_train)` learns the minimum and maximum from training records, then scales them.
- `transform(X_val)` scales validation records using the training-set minimum and maximum.

```python
X_test = np.vstack([X_val, scaler.transform(abnormal)])
y_test = np.concatenate([
    np.zeros(len(X_val), dtype=int),
    np.ones(len(abnormal), dtype=int)
])
```

- `scaler.transform(abnormal)` scales abnormal records using the same scaler.
- `np.vstack(...)` stacks the normal validation records above the abnormal records to form the test input.
- `np.zeros(...)` assigns `0` to each normal record.
- `np.ones(...)` assigns `1` to each abnormal record.
- `np.concatenate(...)` joins those labels into `y_test`.

**Important limitation:** `X_val` is used both to choose the anomaly threshold in Step 4 and as the normal portion of `X_test`. That means those normal records are not an independent test set. A cleaner evaluation would keep a separate normal test set that was not used to set the threshold.

## Step 3: Build and train the autoencoder

```python
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(32, activation="relu"),
    Dense(16, activation="relu"),
    Dense(32, activation="relu"),
    Dense(X_train.shape[1], activation="linear")
])
```

- `Input(shape=(X_train.shape[1],))` sets the input length to the number of values in each ECG record. The summary shows it is **140**.
- `Dense(32, ...)` compresses the 140 input values to 32 values.
- `Dense(16, ...)` compresses them further to a 16-value **latent representation**.
- These first two Dense layers form the encoder.
- `Dense(32, ...)` begins expanding the compressed representation again.
- `Dense(X_train.shape[1], ...)` outputs 140 values, matching the original record length. These last two layers form the decoder.
- `activation="relu"` applies the ReLU function, changing negative values to zero and keeping positive ones.
- `activation="linear"` leaves the output unconstrained, which is useful when reconstructing scaled values.

```python
model.compile(optimizer="adam", loss="mse")
```

- `optimizer="adam"` selects how the model adjusts its weights.
- `loss="mse"` means **Mean Squared Error**: the average squared difference between original and reconstructed values.

```python
model.summary()
```

Displays the model’s layers, output shapes, and number of parameters. The summary shows 140 input values, a 16-value compressed representation, and 140 reconstructed outputs.

```python
history = model.fit(
    X_train, X_train,
    epochs=10,
    batch_size=128,
    validation_split=0.1,
    verbose=0
)
```

- Both the input and target are `X_train`: the autoencoder learns to reproduce its input.
- `epochs=10` trains for 10 passes through the training records.
- `batch_size=128` processes up to 128 records before updating weights.
- `validation_split=0.1` reserves 10% of `X_train` to monitor training.
- `verbose=0` hides progress messages.
- `history` stores the training results.

The autoencoder is trained on normal records so it can learn their patterns. It may reconstruct unfamiliar patterns less accurately, producing larger errors.

## Step 4: Detect abnormal records

```python
val_reconstruction = model.predict(X_val, verbose=0)
val_errors = np.mean(np.square(X_val - val_reconstruction), axis=1)
```

- `model.predict(X_val, ...)` reconstructs each validation record.
- `X_val - val_reconstruction` calculates the difference at each feature.
- `np.square(...)` squares those differences.
- `np.mean(..., axis=1)` averages across the 140 features for each record.
- `val_errors` contains one reconstruction error per validation record.

```python
threshold = np.percentile(val_errors, 95)
```

- `np.percentile(..., 95)` finds the 95th percentile of normal validation errors.
- This value becomes the cutoff: errors above it are flagged as abnormal.

```python
test_reconstruction = model.predict(X_test, verbose=0)
test_errors = np.mean(np.square(X_test - test_reconstruction), axis=1)
y_pred = (test_errors > threshold).astype(int)
```

- `test_reconstruction` contains the reconstructed test records.
- `test_errors` contains the mean squared reconstruction error for each test record.
- `test_errors > threshold` is True for records above the cutoff.
- `.astype(int)` changes True to `1` and False to `0`.
- Here, `1` means predicted abnormal; `0` means predicted normal.

```python
print("Reconstruction-error threshold:", threshold)
print("Actual abnormal records in test:", int(y_test.sum()))
print("Detected abnormal records:", int(y_pred.sum()))
```

- The first line displays the selected cutoff.
- `y_test.sum()` counts actual abnormal records because abnormal labels are `1`.
- `y_pred.sum()` counts records flagged as abnormal.

Your output shows a threshold of **0.03335446**, **2,079** actual abnormal records, and **1,902** records flagged as abnormal. The 1,902 count can include both correctly detected abnormalities and false alarms; it does not tell us how many actual abnormalities were correctly found. A confusion matrix or precision/recall calculation would show that.

### What is an Autoencoder?

An **Autoencoder** is a type of Artificial Neural Network that learns to compress input data and then reconstruct the original data.

It has two main parts:

1. **Encoder:** Compresses the input data into a smaller representation.
2. **Decoder:** Reconstructs the original data from the compressed representation.

### What is ECG?

ECG stands for **Electrocardiogram**.

It is a test that records the electrical activity of the heart.

### What is Anomaly Detection?

Anomaly detection is the process of identifying unusual or abnormal patterns in data.

**Example:**
- Normal ECG signals are reconstructed properly by the model.
- Abnormal ECG signals are reconstructed with larger errors.
- If reconstruction error exceeds a particular threshold, the signal is classified as abnormal.

### Working of Autoencoder

Remember this flow:

**Input ECG → Encoder → Compressed Representation → Decoder → Reconstructed ECG → Calculate Error → Detect Anomaly**

**What is MSE?**

MSE stands for Mean Squared Error.

It calculates the average squared difference between original and reconstructed values.

Formula:

\[
MSE = \frac{1}{n}\sum_{i=1}^{n}(X_i-\hat X_i)^2
\]

Where:

- \(X_i\) = Original value.
- \(\hat X_i\) = Reconstructed value.
- \(n\) = Number of features.

**Remember:** Lower MSE means better reconstruction.

# Step 4: Detect Abnormal ECG Records

This step identifies whether ECG signals are normal or abnormal.

### Part A: Reconstruct Validation Data

```python
val_reconstruction = model.predict(X_val, verbose=0)
```

- `model.predict()` – Generates predictions.
- `X_val` – Normal validation ECG signals.
- `val_reconstruction` – Stores reconstructed ECG signals.

### Part B: Calculate Validation Reconstruction Error

```python
val_errors = np.mean(
    np.square(X_val - val_reconstruction),
    axis=1
)
```

Explanation:

1. `X_val - val_reconstruction` – Calculates the difference between original and reconstructed signals.
2. `np.square()` – Squares the differences.
3. `np.mean()` – Calculates the average squared error.
4. `axis=1` – Calculates error separately for every ECG record.

**Purpose:** Calculates the reconstruction error for each normal validation record.

### Part C: Calculate Threshold

```python
threshold = np.percentile(val_errors, 95)
```

- `np.percentile()` – Calculates a specified percentile.
- `val_errors` – Reconstruction errors of normal validation records.
- `95` – Calculates the 95th percentile.

**What is Threshold?**

A threshold is a fixed error value used to decide whether an ECG signal is normal or abnormal.

In this practical:

- Error ≤ Threshold → Normal.
- Error > Threshold → Abnormal.

Your output:

```text
Reconstruction-error threshold: 0.03335446
```

This means that signals having reconstruction errors greater than approximately 0.03335 are classified as abnormal.

### Part D: Reconstruct Test Data

```python
test_reconstruction = model.predict(X_test, verbose=0)
```

Reconstructs all test ECG signals using the trained autoencoder.

### Part E: Calculate Test Reconstruction Errors

```python
test_errors = np.mean(
    np.square(X_test - test_reconstruction),
    axis=1
)
```

Calculates the reconstruction error for every test ECG record.

### Part F: Identify Abnormal Signals

```python
y_pred = (test_errors > threshold).astype(int)
```

Explanation:

- `test_errors > threshold` – Checks whether each reconstruction error exceeds the threshold.
- If true, the result is 1.
- If false, the result is 0.
- `astype(int)` – Converts True/False into 1/0.
- `y_pred` – Stores predicted classifications.

| Condition | Prediction |
|---|---|
| Error ≤ Threshold | 0 – Normal |
| Error > Threshold | 1 – Abnormal |

### Part G: Display Detection Results

```python
print("Reconstruction-error threshold:", threshold)
```

Displays the calculated threshold.

```python
print("Actual abnormal records in test:", int(y_test.sum()))
```

Displays the actual number of abnormal records.

Why `sum()`?

Because abnormal records are represented by 1 and normal records by 0.

Adding all labels gives the total number of abnormal records.

```python

```

Displays the total number of records predicted as abnormal.

**Important:** 1902 is the total number predicted as abnormal, not necessarily the number correctly detected. To calculate correctly detected abnormalities, we would need to compare `y_pred` with `y_test`.

## Basic Autoencoder Questions

**Q1. What is an Autoencoder?**

An Autoencoder is an artificial neural network that learns to compress input data and reconstruct the original data.

**Q2. What are the two main parts of an Autoencoder?**

1. Encoder – Compresses the input data.
2. Decoder – Reconstructs the original data.

**Q3. What is ECG?**

ECG stands for Electrocardiogram. It records the electrical activity of the heart.

**Q4. What is anomaly detection?**

Anomaly detection is the process of identifying unusual or abnormal patterns in data.

**Q5. Why is an Autoencoder used for ECG anomaly detection?**

It learns normal ECG patterns and identifies abnormal signals using reconstruction errors.

**Q6. What is the difference between normal and abnormal ECG signals in this practical?**

Normal signals generally have lower reconstruction errors, whereas abnormal signals may have higher reconstruction errors.

The ECG dataset stored in `ecg.csv`.

### 7. Three Important Concepts to Understand Properly

These are particularly important because external examiners may ask follow-up questions.

**1. Why train only on normal ECG signals?**

Because the model should learn what normal ECG patterns look like. When it receives an abnormal signal, it may not reconstruct it properly, resulting in a higher reconstruction error.

**2. Why do we need a threshold?**

The threshold helps the model decide whether a signal is normal or abnormal.

- Below or equal to threshold = Normal.
- Above threshold = Abnormal.

**3. What is the difference between Encoder and Decoder?**

- Encoder compresses data.
- Decoder reconstructs data.

**Easy trick to remember:**

Encoder = Compress.

Decoder = Reconstruct.

Autoencoder = Compress + Reconstruct.
