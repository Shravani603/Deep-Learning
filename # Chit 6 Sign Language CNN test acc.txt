# Chit 6: Sign Language CNN: test accuracy

6. Develop a Convolutional Neural Network using TensorFlow/Keras to classify ASL alphabet gestures using the Sign Language MNIST dataset. Reshape the images into 28 × 28 × 1 format, apply convolution and pooling operations, train the model and display test accuracy. 

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
from sklearn.preprocessing import LabelEncoder


# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Reshape the images
X_train = X_train.reshape(-1, 28, 28, 1)
X_test = X_test.reshape(-1, 28, 28, 1)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)



# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)



# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")

# Step 3: Reshape the Images

### Code

```python
X_train = X_train.reshape(-1, 28, 28, 1)

X_test = X_test.reshape(-1, 28, 28, 1)
```

This is one of the most important differences between FNN and CNN.

### What is Reshaping?

Reshaping means changing the dimensions of the image data into the required format.

Here, images are converted into:

```text
28 × 28 × 1
```

| Dimension | Meaning |
|---|---|
| 28 | Image height |
| 28 | Image width |
| 1 | Number of color channels |

**What does 1 represent?**

It represents a grayscale image.

- Grayscale = 1 channel.
- RGB = 3 channels.

### What does `-1` mean?

`-1` automatically calculates the number of images in the dataset.

### Why do we reshape images?

Because Conv2D layers expect image data in four-dimensional format:

```text
(Number of Images, Height, Width, Channels)
```

**Remember:**

FNN uses flattened images (784 features), whereas CNN uses reshaped images (28 × 28 × 1).

# Step 4: Build the CNN Model

### Code

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

This step creates the Convolutional Neural Network.

Let's understand each layer.

## 1. Input Layer

```python
Input(shape=X_train.shape[1:])
```

- Accepts input images.
- Image dimensions are 28 × 28 × 1.
- `shape[1:]` selects the image dimensions, excluding the number of images.

## 2. First Convolutional Layer

```python
Conv2D(32, (3, 3), activation="relu")
```

This layer performs convolution operations.

| Parameter | Meaning |
|---|---|
| `Conv2D` | Performs 2D convolution. |
| `32` | Number of filters. |
| `(3,3)` | Filter or kernel size. |
| `activation="relu"` | Uses ReLU activation function. |

**What is a Filter?**

A filter is a small matrix that moves over an image to extract important features.

For example:
- Edges.
- Shapes.
- Patterns.
- Hand gesture features.

**What is ReLU?**

ReLU stands for Rectified Linear Unit.

It converts negative values into zero and keeps positive values unchanged.

Formula:

```text
f(x) = max(0, x)
```

## 3. First Max Pooling Layer

```python
MaxPooling2D((2, 2))
```

Reduces the size of feature maps by selecting the maximum value from each 2 × 2 region.

**Why do we use Max Pooling?**

1. Reduces image dimensions.
2. Reduces computation.
3. Retains important features.
4. Helps reduce overfitting.

## 4. Second Convolutional Layer

```python
Conv2D(64, (3, 3), activation="relu")
```

- Uses 64 filters.
- Kernel size is 3 × 3.
- Uses ReLU activation.

It extracts more detailed and complex features from the images.

**Why are there 64 filters instead of 32?**

The deeper convolutional layer uses more filters to learn a larger variety of image features.

## 5. Second Max Pooling Layer

```python
MaxPooling2D((2, 2))
```

Reduces the feature map dimensions again.

It keeps the maximum value from each 2 × 2 region.

## 6. Flatten Layer

```python
Flatten()
```

Converts multidimensional feature maps into a one-dimensional array.

**Why do we use Flatten?**

Because Dense layers require one-dimensional input.

## 7. Fully Connected Layer

```python
Dense(128, activation="relu")
```

- Creates a Dense layer with 128 neurons.
- Uses ReLU activation.
- Learns relationships between extracted image features.

## 8. Output Layer

```python
Dense(num_classes, activation="softmax")
```

- Creates 24 output neurons.
- Uses Softmax activation.
- Predicts the probability of each alphabet class.

The alphabet with the highest probability is selected as the final prediction.

Adam stands for Adaptive Moment Estimation.

It updates the weights of the neural network to minimize the loss.

It is a loss function used for multi-class classification when target labels are provided as integers.

```text

```

| FNN | CNN |

| Convolution | Pooling |
|---|---|
| Extracts image features. | Reduces feature map dimensions. |
| Uses filters or kernels. | Uses pooling windows. |

### Difference Between Max Pooling and Average Pooling

| Max Pooling | Average Pooling |
|---|---|
