18. Implement a CNN model to classify different clothing categories. Use Conv2D, MaxPooling2D, Flatten and Dense layers and predict labels for five test images. Use Dataset -  Fashion-MNIST 

import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
import matplotlib.pyplot as plt


# Step 2: Load and prepare Fashion-MNIST
from tensorflow.keras.datasets import fashion_mnist

(X_train, y_train), (X_test, y_test) = fashion_mnist.load_data()
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
class_names = ["T-shirt/top", "Trouser", "Pullover", "Dress", "Coat", "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot"]
image_shape = (28, 28, 1)


# Step 3: Reshape the images
X_train = X_train[..., np.newaxis]
X_test = X_test[..., np.newaxis]


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)


# Step 7: Predict test images
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)


# Step 8: Show five examples
plt.figure(figsize=(14, 4))
for i in range(5):
    image = X_test[i].reshape(image_shape)
    plt.subplot(1, 5, i + 1)
    if image_shape[-1] == 1:
        plt.imshow(image.squeeze(), cmap="gray")
    else:
        plt.imshow(image)
    plt.title(f"Actual: {class_names[int(y_test[i])]}\nPredicted: {class_names[int(y_pred[i])]}")
    plt.axis("off")
plt.tight_layout()
plt.show()



























# Chit 18: Fashion-MNIST CNN — Five Clothing Predictions

## Aim

Build a Convolutional Neural Network (CNN) to classify Fashion-MNIST clothing images, then display actual and predicted labels for five test images.

## How the CNN works

```text
28 × 28 grayscale image → Conv2D → MaxPooling2D → Conv2D → MaxPooling2D
                         → Flatten → Dense(128) → Softmax(10 classes)
```

Convolution layers learn image patterns. Pooling layers reduce the feature-map size. The Dense layers use the learned features to predict a clothing category.

## Step 1: Import the libraries

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
import matplotlib.pyplot as plt
```

- `numpy as np` imports NumPy. It is used later for `np.newaxis` and `np.argmax()`.
- `tensorflow as tf` imports TensorFlow, but `tf` is not directly used in this code.
- `Sequential` creates a model with layers arranged in order.
- `Input` defines the shape of each input image.
- `Dense` creates fully connected layers.
- `Conv2D` learns image patterns using filters.
- `MaxPooling2D` reduces the size of feature maps.
- `Flatten` turns feature maps into a one-dimensional list.
- `matplotlib.pyplot as plt` displays the images and their labels.

## Step 2: Load and prepare Fashion-MNIST

```python
from tensorflow.keras.datasets import fashion_mnist

(X_train, y_train), (X_test, y_test) = fashion_mnist.load_data()
```

- `fashion_mnist` is the clothing image dataset provided by Keras.
- `load_data()` loads the images and their correct labels.
- `X_train`, `y_train` contain training images and labels.
- `X_test`, `y_test` contain separate test images and labels.

```python
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
```

- `.astype("float32")` converts pixel values to decimal numbers.
- `/ 255.0` scales pixel values from 0–255 to 0–1. This is called **normalization**.

```python
class_names = [
    "T-shirt/top", "Trouser", "Pullover", "Dress", "Coat",
    "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot"
]
image_shape = (28, 28, 1)
```

- `class_names` maps the numeric labels 0–9 to clothing names, in the dataset’s class order.
- `image_shape` describes a 28 × 28 grayscale image with one channel. It is used later when displaying images.

## Step 3: Reshape the images

```python
X_train = X_train[..., np.newaxis]
X_test = X_test[..., np.newaxis]
```

The original images have shape `(number of images, 28, 28)`. CNNs expect a channel dimension too, so these lines make the shape:

```text
(number of images, 28, 28, 1)
```

- `...` keeps all existing dimensions.
- `np.newaxis` adds a new dimension at the end.
- `1` means each image has one grayscale channel.

## Step 4: Build the model

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

- `num_classes` counts the clothing categories: 10.
- `Sequential([...])` arranges the model’s layers in order.
- `Input(shape=X_train.shape[1:])` gives the model the shape `(28, 28, 1)`, excluding the number of images.
- `Conv2D(32, (3, 3), ...)` learns 32 filters. Each filter scans a 3 × 3 image region.
- `MaxPooling2D((2, 2))` reduces feature maps by selecting the largest value from each 2 × 2 region.
- The second `Conv2D` learns 64 filters to detect more complex patterns.
- The second pooling layer reduces the maps again.
- `Flatten()` converts the feature maps into a one-dimensional list.
- `Dense(128, ...)` combines the learned features using 128 neurons.
- `Dense(num_classes, ...)` creates 10 output neurons, one per clothing category.
- `activation="relu"` changes negative values to zero and keeps positive values.
- `activation="softmax"` converts output scores into probabilities. The highest probability is the predicted class.

## Step 5: Compile and train

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

- `optimizer="adam"` selects how the model updates its weights during training.
- `loss="sparse_categorical_crossentropy"` measures how far predictions are from the correct integer labels.
- `metrics=["accuracy"]` asks Keras to track the fraction of correct predictions.

“Sparse” is appropriate because the labels are class numbers, not one-hot vectors.

```python
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)
```

- `model.fit(...)` trains the CNN using the training images and labels.
- `epochs=10` means the model processes the training data 10 times.
- `batch_size=128` means it processes up to 128 images before updating its weights.
- `verbose=0` hides the training progress messages.

## Step 6: Predict test images

```python
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)
```

- `model.predict(X_test, ...)` returns class scores for each test image.
- `np.argmax(..., axis=1)` finds the position of the largest score for each image.
- `y_pred` stores the predicted class numbers.
- `axis=1` means it selects the highest score across the classes for each image.

## Step 7: Display five examples

```python
plt.figure(figsize=(14, 4))
```

Creates a figure 14 inches wide and 4 inches high.

```python
for i in range(5):
    image = X_test[i].reshape(image_shape)
    plt.subplot(1, 5, i + 1)
```

- `for i in range(5)` repeats the display steps five times, for images 0 through 4.
- `X_test[i]` selects one test image.
- `.reshape(image_shape)` gives it the shape `(28, 28, 1)` for display.
- `plt.subplot(1, 5, i + 1)` lays out five images in one row and selects the current position. Positions start at 1, hence `i + 1`.

```python
    if image_shape[-1] == 1:
        plt.imshow(image.squeeze(), cmap="gray")
    else:
        plt.imshow(image)
```

- `image_shape[-1]` checks the final shape value: the number of channels.
- `if ... == 1` checks whether the image is grayscale.
- `.squeeze()` removes the extra one-channel dimension so the image can be displayed.
- `cmap="gray"` displays it using shades of gray.
- `else` would display an image with more than one channel.

```python
    plt.title(
        f"Actual: {class_names[int(y_test[i])]}
Predicted: {class_names[int(y_pred[i])]}"
    )
    plt.axis("off")
```

- `plt.title(...)` displays a title above the image.
- `y_test[i]` is the actual class number; `y_pred[i]` is the predicted class number.
- `class_names[...]` converts each number into a clothing name.
- `int(...)` ensures the value is an integer for indexing the list.
- `\n` puts the predicted label on a new line.
- `plt.axis("off")` hides the axes.

```python
plt.tight_layout()
plt.show()
```

- `plt.tight_layout()` adjusts spacing so the images and titles fit.
- `plt.show()` displays the figure.

### Step 4: Build the CNN Model

```python
num_classes = len(class_names)

model = Sequential([
```

This is the most important part of the practical.

Let's understand each layer.

**1. Number of classes**

```python
num_classes = len(class_names)
```

- Calculates the number of clothing categories.
- Here, `num_classes = 10`.

**2. Sequential model**

```python
model = Sequential([...])
```

Creates a CNN in which layers are arranged one after another.

**3. Input layer**

```python
Input(shape=X_train.shape[1:])
```

- Defines the shape of each input image.
- `X_train.shape[1:]` gives `(28, 28, 1)`.
- The model accepts 28 × 28 grayscale images.

**4. First Convolutional Layer**

```python
Conv2D(32, (3, 3), activation="relu")
```

- `Conv2D` performs convolution.
- `32` represents the number of filters.
- `(3,3)` represents the size of each filter.
- ReLU is the activation function.

**What is convolution?**

Convolution is an operation in which small filters slide over an image to identify important features.

For clothing images, it can help identify:
- Edges.
- Curves.
- Shapes.
- Clothing outlines.
- Patterns and textures.

**What is a filter?**

A filter is a small matrix that moves over an image to extract specific features.

Here, the first convolutional layer uses 32 filters of size 3 × 3.

**5. First Max-Pooling Layer**

```python
MaxPooling2D((2, 2))
```

- Performs max-pooling.
- Uses a 2 × 2 pooling window.
- Selects the maximum value from each 2 × 2 region.
- Reduces the spatial dimensions of feature maps.

**Why do we use Max-Pooling?**

1. Reduces feature map dimensions.
2. Reduces computational requirements.
3. Retains important features.
4. Makes the model less sensitive to small changes in image position.

**6. Second Convolutional Layer**

```python
Conv2D(64, (3, 3), activation="relu")
```

- Uses 64 filters.
- Each filter has a size of 3 × 3.
- Extracts more complex features from the previous feature maps.
- Uses ReLU activation.

**7. Second Max-Pooling Layer**

```python
MaxPooling2D((2, 2))
```

- Uses a 2 × 2 pooling window.
- Reduces feature map dimensions further.
- Retains the maximum values from each region.

**8. Flatten Layer**

```python
Flatten()
```

- Converts multidimensional feature maps into a one-dimensional array.
- Makes the data suitable for Dense layers.

**9. Dense Hidden Layer**

```python
Dense(128, activation="relu")
```

- Contains 128 neurons.
- Uses ReLU activation.
- Learns patterns from the features extracted by convolutional layers.

**10. Output Layer**

```python
Dense(num_classes, activation="softmax")
```

- Contains 10 neurons.
- Each neuron represents one clothing category.
- Softmax produces probabilities for all 10 classes.
- The category with the highest probability is selected as the prediction.

### CNN Architecture Diagram

```text
          Input Image
         28 × 28 × 1
               |
               ↓
      Convolutional Layer 1
        32 Filters (3 × 3)
          ReLU Activation
               |
               ↓
        Max-Pooling Layer
            (2 × 2)
               |
               ↓
      Convolutional Layer 2
        64 Filters (3 × 3)
          ReLU Activation
               |
               ↓
        Max-Pooling Layer
            (2 × 2)
               |
               ↓
          Flatten Layer
               |
               ↓
           Dense Layer
           128 Neurons
          ReLU Activation
               |
               ↓
          Output Layer
           10 Neurons
        Softmax Activation
               |
               ↓
     Predicted Clothing Category
```

### Understanding Dimensions After Each Layer

| Layer | Output shape (excluding batch size) |
|---|---|
| Input | 28 × 28 × 1 |
| Conv2D (32 filters) | 26 × 26 × 32 |
| MaxPooling2D | 13 × 13 × 32 |
| Conv2D (64 filters) | 11 × 11 × 64 |
| MaxPooling2D | 5 × 5 × 64 |
| Flatten | 1600 |
| Dense | 128 |
| Output | 10 |

**How are these dimensions calculated?**

- First convolution: 28 − 3 + 1 = 26.
- First pooling: 26 ÷ 2 = 13.
- Second convolution: 13 − 3 + 1 = 11.
- Second pooling: 11 × 11 becomes 5 × 5.
- Flatten: 5 × 5 × 64 = 1600.

Note: The convolution layers use valid padding by default, meaning no extra padding is added around the image.

## 4. Important Viva Questions and Answers

### Q1. What is Fashion-MNIST?
Fashion-MNIST is a dataset containing grayscale images of clothing items used for image classification.

### Q2. How many images are present in Fashion-MNIST?
It contains 70,000 images:
- 60,000 training images.
- 10,000 testing images.

### Q3. How many classes are present?
There are 10 clothing categories.

### Q4. Name the 10 categories.
T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag and Ankle boot.

### Q5. What is CNN?
CNN stands for Convolutional Neural Network. It is a deep learning model mainly used for image processing and image classification.

### Q6. Why do we use CNN for clothing classification?
CNN automatically extracts important image features such as edges, shapes and patterns, making it suitable for image classification.

### Q7. What is convolution?
Convolution is an operation in which filters slide over an image to extract important features.

### Q8. What is a filter in CNN?
A filter is a small matrix that moves over an image to detect features such as edges, curves and patterns.

### Q9. What is the filter size used in this practical?
The filter size is 3 × 3 in both convolutional layers.

### Q10. How many filters are used in the first convolutional layer?
32 filters.

### Q11. How many filters are used in the second convolutional layer?
64 filters.

### Q12. What is Max-Pooling?
Max-pooling is a downsampling operation that selects the maximum value from a small region of a feature map.

### Q13. What is the pooling size used?
2 × 2.

### Q14. Why do we use Max-Pooling?
It reduces feature map dimensions, reduces computation and retains important features.

### Q15. What is a feature map?
A feature map is the output produced after applying a filter to an image or previous feature maps.

### Q16. What is ReLU?
ReLU stands for Rectified Linear Unit. It converts negative values into zero and keeps positive values unchanged.

Formula:

`ReLU(x) = max(0, x)`

### Q17. Why do we use Flatten?
Flatten converts multidimensional feature maps into a one-dimensional array before passing them to Dense layers.

### Q18. What is the purpose of the Dense layer?
Dense layers use the extracted features to perform final classification.

### Q19. Why does the output layer contain 10 neurons?
Because Fashion-MNIST contains 10 clothing categories.

### Q20. What is Softmax?
Softmax converts output values into probabilities for different classes. The class with the highest probability is selected.

### Q21. Why do we use `np.newaxis`?
It adds a channel dimension to image data so that it matches the input format expected by Conv2D.

### Q22. Why is the channel value 1?
Because Fashion-MNIST images are grayscale and contain only one channel.

### Q23. What is `np.argmax()`?
It returns the index of the highest value in an array. Here, it identifies the predicted clothing category.

### Q24. What is `axis=1`?
It tells NumPy to find the highest probability across the class dimension for each image.

### Q25. What is the purpose of `model.predict()`?
It uses the trained model to generate predictions for new or testing images.

### Q26. What is the difference between actual and predicted labels?
- Actual label is the correct category provided in the dataset.
- Predicted label is the category identified by the trained model.

### Q27. Why do we use Matplotlib?
Matplotlib is used to display the five test images along with their actual and predicted labels.

### Q28. What is `plt.subplot(1,5,i+1)`?
It creates a layout of one row and five columns and selects the position for the current image.

### Q29. What does `image.squeeze()` do?
It removes dimensions of size 1. Here, it converts `(28,28,1)` into `(28,28)` for grayscale display.

### Q30. What is the difference between CNN and FNN?
- FNN uses flattened images and fully connected layers.
- CNN uses convolution and pooling layers to extract spatial features.
- CNN is generally more suitable for image classification.

### Q31. What is an epoch?
One complete pass through the entire training dataset is called an epoch.

### Q32. What is batch size?
The number of training samples processed before updating model weights is called batch size.

### Q33. Which optimizer is used?
Adam optimizer.

### Q34. Which loss function is used?
Sparse categorical crossentropy.

No. It predicts the test images and displays five actual and predicted labels. It does not calculate or print testing accuracy.
