# Chit 5: Sign Language FNN: confusion matrix

5. Build a Feedforward Neural Network for ASL alphabet classification. Evaluate the trained model using test data and generate a confusion matrix to identify correctly and incorrectly classified alphabet gestures. 

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from sklearn.preprocessing import LabelEncoder
import matplotlib.pyplot as plt
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay, classification_report


# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Flatten the images
X_train = X_train.reshape(-1, 28, 28).reshape(-1, 784)
X_test = X_test.reshape(-1, 28, 28).reshape(-1, 784)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)



# Step 7: Predict test images
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)


# Step 8: Confusion matrix
cm = confusion_matrix(y_test, y_pred, labels=np.arange(num_classes))
display = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=class_names)
fig, ax = plt.subplots(figsize=(10, 10))
display.plot(ax=ax, xticks_rotation="vertical", colorbar=False, cmap="Blues", values_format="d")
plt.title("Confusion Matrix")
plt.tight_layout()
plt.show()



# Step 9: Classification report
print("\nClassification Report:")
print(classification_report(
    y_test,
    y_pred,
    labels=np.arange(24),
    target_names=class_names
))

The classification report contains five important values.

## A. Precision

Precision tells us how many images predicted as a particular alphabet were actually correct.

**Formula:**

Precision = TP / (TP + FP)

Where:

- TP = True Positive.
- FP = False Positive.

Example:

If the model predicts 100 images as A and 80 are actually A:

Precision = 80/100 = 0.80 = 80%.

## B. Recall

Recall tells us how many actual images of a particular alphabet were correctly identified.

**Formula:**

Recall = TP / (TP + FN)

Where:

- TP = True Positive.
- FN = False Negative.

Example:

If there are 100 actual A images and the model correctly identifies 90:

Recall = 90/100 = 90%.

## C. F1-Score

F1-score is the harmonic mean of precision and recall.

It balances both precision and recall.

**Formula:**

F1-score = 2 × (Precision × Recall) / (Precision + Recall)

Higher F1-score generally indicates better classification performance.

## D. Support

Support represents the total number of actual samples belonging to each class in the testing dataset.

Example:

```text
A    331
B    432
C    310
```

It means:

- 331 actual A images.
- 432 actual B images.
- 310 actual C images.

## E. Accuracy

Accuracy represents the percentage of correctly classified images out of all testing images.

**Formula:**

Accuracy = Correct Predictions / Total Predictions
