# Chit 16: Fashion-MNIST FNN: confusion matrix

16. Build a Feedforward Neural Network for clothing image classification. Evaluate the model using test data and generate a confusion matrix. Use Dataset -- Fashion-MNIST 

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import matplotlib.pyplot as plt
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay


# Step 2: Load and prepare Fashion-MNIST
from tensorflow.keras.datasets import fashion_mnist

(X_train, y_train), (X_test, y_test) = fashion_mnist.load_data()
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
class_names = ["T-shirt/top", "Trouser", "Pullover", "Dress", "Coat", "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot"]
image_shape = (28, 28, 1)


# Step 3: Flatten the images
X_train = X_train.reshape(len(X_train), 784)
X_test = X_test.reshape(len(X_test), 784)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)


# Step 7: Predict test images
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)


# Step 8: Confusion matrix
cm = confusion_matrix(y_test, y_pred, labels=np.arange(num_classes))
display = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=class_names)
fig, ax = plt.subplots(figsize=(10, 10))
display.plot(ax=ax, xticks_rotation="vertical", colorbar=False, cmap="Blues", values_format="d")
plt.title("Confusion Matrix")
plt.tight_layout()
plt.show()





















# Chit 16: Fashion-MNIST FNN — Confusion Matrix

## Aim

Train a Feedforward Neural Network (FNN) to classify Fashion-MNIST clothing images, predict labels for the test images, and use a confusion matrix to see which classes the model predicts correctly or confuses with other classes.

## How it works

```text
28 × 28 image → flatten to 784 values → Dense(256) → Dense(128)
→ Softmax(10 classes) → test predictions → confusion matrix
```

## Step 1: Import the libraries

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import matplotlib.pyplot as plt
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay
```

- `numpy as np` is used to select each image’s highest scoring predicted class.
- `tensorflow as tf` imports TensorFlow but is not directly used later.
- `Sequential` creates a model with layers in order.
- `Input` defines the model’s input shape.
- `Dense` creates fully connected neural network layers.
- `matplotlib.pyplot as plt` displays the confusion matrix.
- `confusion_matrix` calculates how predictions compare with the actual labels.
- `ConfusionMatrixDisplay` displays those counts as a labeled matrix.

## Step 2: Load and prepare Fashion-MNIST

```python
from tensorflow.keras.datasets import fashion_mnist

(X_train, y_train), (X_test, y_test) = fashion_mnist.load_data()
```

- `fashion_mnist` is the Fashion-MNIST dataset provided by Keras.
- `load_data()` loads the images and their labels.
- `X_train`, `y_train` contain training images and correct class numbers.
- `X_test`, `y_test` contain separate test images and correct class numbers.

```python
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
```

- `.astype("float32")` converts pixel values to decimal numbers.
- `/ 255.0` scales the pixels from 0–255 to 0–1. This is called **normalization**.

```python
class_names = [
    "T-shirt/top", "Trouser", "Pullover", "Dress", "Coat",
    "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot"
]
image_shape = (28, 28, 1)
```

- `class_names` maps class numbers 0–9 to clothing labels in the dataset’s class order.
- `image_shape` describes a 28 × 28 grayscale image with one channel. It is not used later in this code.

## Step 3: Flatten the images

```python
X_train = X_train.reshape(len(X_train), 784)
X_test = X_test.reshape(len(X_test), 784)
```

- `len(X_train)` and `len(X_test)` give the number of images.
- `784` is the number of pixels in each image: `28 × 28`.
- `.reshape(...)` turns each 28 × 28 image into a one-dimensional list of 784 values. This is called **flattening**.
- Dense layers receive each image as a vector.

## Step 4: Build the model

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

- `num_classes` counts the categories: 10.
- `Sequential([...])` arranges the layers in order.
- `Input(shape=(X_train.shape[1],))` tells the model each image has 784 input values.
- `Dense(256, ...)` and `Dense(128, ...)` create hidden layers with 256 and 128 neurons.
- `activation="relu"` changes negative values to zero and keeps positive values.
- `Dense(num_classes, ...)` creates 10 output neurons, one for each clothing class.
- `activation="softmax"` converts output scores into probabilities. The highest probability is the predicted class.

## Step 5: Compile and train

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

- `optimizer="adam"` selects how the model updates its weights during training.
- `loss="sparse_categorical_crossentropy"` measures the difference between the predictions and the correct integer labels.
- `metrics=["accuracy"]` asks Keras to track the fraction of correct predictions.

“Sparse” is suitable because the labels are class numbers, not one-hot vectors.

```python
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)
```

- `model.fit(...)` trains the model using the training images and labels.
- `epochs=15` means the model goes through the training data 15 times.
- `batch_size=128` means it processes up to 128 images before updating its weights.
- `verbose=0` hides progress messages.

## Step 6: Predict test images

```python
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)
```

- `model.predict(X_test, ...)` returns scores for each class for every test image.
- `np.argmax(..., axis=1)` selects the class with the highest score for each image.
- `y_pred` stores the predicted class numbers.

## Step 7: Create and display the confusion matrix

```python
cm = confusion_matrix(y_test, y_pred, labels=np.arange(num_classes))
```

- `confusion_matrix(...)` compares actual labels with predicted labels.
- `y_test` provides the correct class numbers.
- `y_pred` provides the predicted class numbers.
- `labels=np.arange(num_classes)` sets the class order to 0 through 9.
- `cm` stores the counts in a 10 × 10 array.

```python
display = ConfusionMatrixDisplay(
    confusion_matrix=cm,
    display_labels=class_names
)
```

Creates a display object that pairs the count matrix with the clothing names.

```python
fig, ax = plt.subplots(figsize=(10, 10))
```

Creates a 10 × 10 inch figure and an axes area, `ax`, where the matrix will be drawn. `fig` refers to the whole figure.

```python
display.plot(
    ax=ax,
    xticks_rotation="vertical",
    colorbar=False,
    cmap="Blues",
    values_format="d"
)
```

- `ax=ax` draws the matrix on the axes created above.
- `xticks_rotation="vertical"` rotates the predicted-label names so they fit.
- `colorbar=False` hides the color scale bar.
- `cmap="Blues"` uses shades of blue.
- `values_format="d"` displays counts as whole numbers.

```python
plt.title("Confusion Matrix")
plt.tight_layout()
plt.show()
```

- `plt.title(...)` adds the graph title.
- `plt.tight_layout()` adjusts spacing.
- `plt.show()` displays the matrix.

## How to read the confusion matrix

- **Rows** are the actual classes.
- **Columns** are the predicted classes.
- **Diagonal cells** show correct predictions: actual and predicted labels match.
- **Off-diagonal cells** show errors: the model predicted a different class.
- Darker cells have larger counts.

Examples from your matrix:

- Of the actual **T-shirt/top** images, **882** were correctly predicted as T-shirt/top; **63** were predicted as Shirt.
- Of the actual **Shirt** images, **659** were correctly predicted; **170** were predicted as T-shirt/top and **81** as Pullover.
- Of the actual **Trouser** images, **970** were correctly predicted.
- Of the actual **Sandal** images, **984** were correctly predicted.

The matrix shows that the model often confuses visually similar clothing categories, especially Shirt with T-shirt/top or Pullover.

The network has two hidden Dense layers with ReLU and a 10-class Softmax output. After training, it predicts labels for the test images. `confusion_matrix` compares those predictions with the actual labels, and `ConfusionMatrixDisplay` plots the results.
