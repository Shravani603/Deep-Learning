4. Implement a Feedforward Neural Network for Sign Language recognition using two hidden Dense layers. Train the model and display its accuracy and loss. Also, observe the model's performance on sample test images. 

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from sklearn.preprocessing import LabelEncoder
import matplotlib.pyplot as plt


# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Flatten the images
X_train = X_train.reshape(-1, 28, 28).reshape(-1, 784)
X_test = X_test.reshape(-1, 28, 28).reshape(-1, 784)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])



# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)


# Step 7: Evaluate on test data
test_loss, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")
print(f"Testing loss: {test_loss:.4f}")

# Step 8: Predict test images
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)


# Step 9: Show five examples
plt.figure(figsize=(14, 4))
for i in range(5):
    image = X_test[i].reshape(image_shape)
    plt.subplot(1, 5, i + 1)
    if image_shape[-1] == 1:
        plt.imshow(image.squeeze(), cmap="gray")
    else:

## Step 3: Flatten the Images

### Code


### What is Flattening?

Flattening means converting a two-dimensional image into a one-dimensional array.

Original image:

```text
28 × 28 pixels
```

After flattening:

```text
784 features
```

Because:

28 × 28 = 784.

### Understanding `reshape()`

- `reshape()` changes the dimensions of an array.
- `-1` automatically calculates the number of images.
- `28, 28` represents image height and width.
- `784` represents the total number of pixels.

**Why do we flatten images?**

Because Dense layers expect one-dimensional feature vectors for each input image.

# 5. Important Code Issue – Training Accuracy

Your code contains:

```python
# Display training accuracy
train_accuracy = history.history["accuracy"][-1]
print("Training Accuracy:", train_accuracy * 100, "%")
```

There is a small mistake here.

You have written:

```python
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)
```

But you have not stored the training history in a variable.

Later, you are trying to access:

```python
history.history["accuracy"]
```

However, `history` has not been defined in this code.

### What is the correct code?

Replace:

```python
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)
```

With:

```python
history = model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)
```

Now the training accuracy code will work:

```python
train_accuracy = history.history["accuracy"][-1]
print("Training Accuracy:", train_accuracy * 100, "%")
```

### Why do we use `history`?

`model.fit()` returns a History object containing information about training.

It stores:
- Training accuracy.
- Training loss.
- Validation accuracy, if validation is used.
- Validation loss, if validation is used.

**Important:** If you executed Practical 2 before Practical 4 in the same Jupyter Notebook, an old `history` variable might still exist. In that case, your code might display the previous practical's training accuracy instead of Practical 4's accuracy.

Always assign the current training result to `history`.
