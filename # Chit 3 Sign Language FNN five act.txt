3. Develop an FNN model to classify grayscale hand gesture images into their corresponding alphabet classes. Display any five test images along with their actual and predicted alphabet labels. 


# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from sklearn.preprocessing import LabelEncoder
import matplotlib.pyplot as plt


# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Flatten the images
X_train = X_train.reshape(-1, 28, 28).reshape(-1, 784)
X_test = X_test.reshape(-1, 28, 28).reshape(-1, 784)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])



# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)



# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=15, batch_size=128, verbose=0)


# Step 7: Predict test images
y_pred = np.argmax(model.predict(X_test, verbose=0), axis=1)



# Step 8: Show five examples
plt.figure(figsize=(14, 4))

for i in range(5):
    image = X_test[i].reshape(image_shape)

    plt.subplot(1, 5, i + 1)

    if image_shape[-1] == 1:
        plt.imshow(image.squeeze(), cmap="gray")
    else:
        plt.imshow(image)

    plt.title(
        f"Actual: {class_names[int(y_test[i])]}\n"
        f"Predicted: {class_names[int(y_pred[i])]}"
    )
    plt.axis("off")

plt.tight_layout()
plt.show()

# 4. Step 7: Predict Test Images

**This is one of the MOST IMPORTANT parts of Practical 3.**

### Code

```python

```

This line predicts the alphabet classes for all testing images.

Let's break it down.

### 1. `model.predict(X_test, verbose=0)`

- `model.predict()` – Makes predictions using the trained model.
- `X_test` – Contains testing images.
- `verbose=0` – Hides prediction progress.

**What does predict() return?**

It returns probabilities for all 24 classes for every testing image.

Example:

Suppose the model predicts the following probabilities for one image:

| Alphabet | Probability |
|---|---:|
| A | 0.05 |
| B | 0.10 |
| C | 0.70 |
| D | 0.15 |

The highest probability is 0.70, which belongs to C.

### 2. `np.argmax()`

`argmax()` returns the index of the highest value.

Example:

```python
probabilities = [0.05, 0.10, 0.70, 0.15]

np.argmax(probabilities)
```

Output:

```text
2
```

Because 0.70 is at index 2.

### 3. `axis=1`

Specifies that we should find the highest probability across each row.

In simple language:

- Each row represents one image.
- Each column represents one alphabet class.
- `axis=1` finds the predicted class for every image.

### 4. `y_pred`

Stores the predicted numerical class indices.

**Complete meaning of this line:**

The trained model predicts probabilities for testing images, and `np.argmax()` selects the class having the highest probability for each image.

### Important Viva Questions

**Q. What is `model.predict()`?**

**Q. What is `argmax()`?**

It returns the index of the maximum value.

**Q. Why do we use `axis=1`?**

To find the highest probability separately for each testing image.
