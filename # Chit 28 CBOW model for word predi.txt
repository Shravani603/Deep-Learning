28. CBOW Model for Word Prediction 
Implement a Continuous Bag of Words (CBOW) model using Python to predict a target word based on its surrounding context words. Perform the following steps: 
a. Data Preparation: Create a sample text corpus, convert the text into lowercase, remove punctuation and tokenize the sentences into words. 
b. Generate Training Data: Build a vocabulary, assign a unique index to each word and generate CBOW training pairs consisting of context words and their corresponding target words. 
c. Train Model: Build a simple CBOW neural network using an Embedding layer and Dense layer. Train the model using the generated training data to learn word representations. 
d. Output: Display the vocabulary, sample context-target pairs, training loss and predicted target word for a given set of context words. 




# Step 1: Prepare a text corpus
import re
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Embedding, GlobalAveragePooling1D, Dense

with open("document3.txt", encoding="utf-8") as file:
    text = file.read()

text = re.sub(r"[^a-z\s]", " ", text.lower())
words = text.split()
vocabulary = sorted(set(words))
word_to_id = {word: i for i, word in enumerate(vocabulary)}
id_to_word = {i: word for word, i in word_to_id.items()}
print("Vocabulary:", vocabulary)


# Step 2: Make context and target pairs
window_size = 2
contexts, targets = [], []
for i in range(window_size, len(words) - window_size):
    context_words = words[i-window_size:i] + words[i+1:i+window_size+1]
    contexts.append([word_to_id[word] for word in context_words])
    targets.append(word_to_id[words[i]])

X = np.array(contexts, dtype="int32")
y = np.array(targets, dtype="int32")
for i in range(min(5, len(X))):
    print([id_to_word[index] for index in X[i]], "->", id_to_word[y[i]])



# Step 3: Train the CBOW network
embedding_size = 16
model = Sequential([
    Input(shape=(2 * window_size,)),
    Embedding(input_dim=len(vocabulary), output_dim=embedding_size),
    GlobalAveragePooling1D(),
    Dense(len(vocabulary), activation="softmax")
])
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
history = model.fit(X, y, epochs=100, verbose=0)
print("Final training loss:", round(history.history["loss"][-1], 4))


# Step 4: Predict a target word
sample_context = X[0]
prediction = model.predict(sample_context.reshape(1, -1), verbose=0)
predicted_word = id_to_word[int(np.argmax(prediction[0]))]
print("Context:", [id_to_word[index] for index in sample_context])
print("Predicted target:", predicted_word)





















# Chit 28: CBOW Model for Word Prediction

## Aim

Implement a **Continuous Bag of Words (CBOW)** model that predicts a target word from the words around it. The model learns word embeddings from the text in `document3.txt`.

## How CBOW works

With `window_size = 2`, the model uses two words before and two words after the target:

```text
left context             target           right context
[the, speed]  +  [ ? ]  +  [is, of]  →  predict the missing word
```

It converts each context word into an embedding, averages those embeddings, then predicts a word from the vocabulary.

## Step 1: Read and prepare the text

```python
import re
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Embedding, GlobalAveragePooling1D, Dense
```

- `re` provides regular expressions for text cleaning.
- `numpy as np` creates the training arrays.
- `Sequential` builds a model with layers in order.
- `Input` defines the model’s input shape.
- `Embedding` learns a vector representation for each word.
- `GlobalAveragePooling1D` averages the context word vectors.
- `Dense` creates the output layer that predicts the target word.

```python
with open("document3.txt", encoding="utf-8") as file:
    text = file.read()
```

- `open(...)` opens the text file.
- `"document3.txt"` is the file to read.
- `encoding="utf-8"` tells Python how to interpret its characters.
- `with` closes the file automatically when reading finishes.
- `file.read()` reads all the text into `text`.

```python
text = re.sub(r"[^a-z\s]", " ", text.lower())
```

- `text.lower()` changes all letters to lowercase.
- `re.sub(pattern, replacement, text)` replaces text matching a pattern.
- `r"..."` marks the pattern as a raw string.
- `[^a-z\s]` matches any character that is not a lowercase letter or whitespace.
- Matching characters, including punctuation and digits, are replaced with spaces.

```python
words = text.split()
```

Splits the cleaned text at whitespace, creating a list of word tokens.

```python
vocabulary = sorted(set(words))
```

- `set(words)` keeps one copy of each unique word.
- `sorted(...)` puts those words in alphabetical order.
- `vocabulary` is the list of all unique words the model can predict.

```python
word_to_id = {word: i for i, word in enumerate(vocabulary)}
id_to_word = {i: word for word, i in word_to_id.items()}
print("Vocabulary:", vocabulary)
```

- `enumerate(vocabulary)` pairs each word with an index, starting at 0.
- `word_to_id` maps words to numbers for the model.
- `word_to_id.items()` gives word-number pairs.
- `id_to_word` reverses that mapping, so numbers can be converted back to words.
- `print(...)` displays the vocabulary.

## Step 2: Make context and target pairs

```python
window_size = 2
contexts, targets = [], []
```

- `window_size = 2` means the model uses two words on either side of each target.
- `contexts` will store surrounding-word indices.
- `targets` will store the target-word indices.

```python
for i in range(window_size, len(words) - window_size):
```

Loops through the words that have two words before and after them. The first and last two words are skipped because they do not have a complete context window.

```python
    context_words = words[i-window_size:i] + words[i+1:i+window_size+1]
```

Builds the context for the word at position `i`:

- `words[i-window_size:i]` selects the two words before it.
- `words[i+1:i+window_size+1]` selects the two words after it.
- The `+` joins those two lists.
- `words[i]` itself is excluded from the context because it is the target.

```python
    contexts.append([word_to_id[word] for word in context_words])
    targets.append(word_to_id[words[i]])
```

- The list comprehension converts each context word to its index.
- `contexts.append(...)` saves those four word indices.
- `word_to_id[words[i]]` gets the index of the centre word.
- `targets.append(...)` saves that centre word as the answer.

```python
X = np.array(contexts, dtype="int32")
y = np.array(targets, dtype="int32")
```

- `X` stores the context indices as a NumPy array.
- `y` stores the target indices.
- `dtype="int32"` makes each index a 32-bit integer.

```python
for i in range(min(5, len(X))):
    print([id_to_word[index] for index in X[i]], "->", id_to_word[y[i]])
```

- `min(5, len(X))` prints up to five pairs, or fewer if there are fewer examples.
- `X[i]` selects one context.
- `id_to_word[index]` converts each context number back into a word.
- `y[i]` gives the target index, and `id_to_word[y[i]]` converts it back to a word.
- The arrow shows the context-to-target relationship.

For example:

```text
['the', 'speed', 'transmission', 'is'] -> of
```

The four context words surround the target word `of` in the corpus.

## Step 3: Train the CBOW network

```python
embedding_size = 16
```

Each vocabulary word will be represented by a vector of 16 learned numbers.

```python
model = Sequential([
    Input(shape=(2 * window_size,)),
    Embedding(input_dim=len(vocabulary), output_dim=embedding_size),
    GlobalAveragePooling1D(),
    Dense(len(vocabulary), activation="softmax")
])
```

- `Input(shape=(2 * window_size,))` sets the context length. With `window_size = 2`, each input has four word indices.
- `Embedding(...)` looks up a 16-number vector for each context word.
  - `input_dim=len(vocabulary)` is the number of unique words.
  - `output_dim=embedding_size` is the vector length, here 16.
- `GlobalAveragePooling1D()` averages the four context vectors into one vector. This is the “bag of words” step: it uses the context words without modelling their order.
- `Dense(len(vocabulary), ...)` creates one output score for every possible target word.
- `activation="softmax"` turns those scores into probabilities across the vocabulary.

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

- `optimizer="adam"` selects how the model updates its learned values.
- `loss="sparse_categorical_crossentropy"` measures prediction error when target labels are integer word indices.
- `metrics=["accuracy"]` asks Keras to track how often the highest-probability word matches the target.

```python
history = model.fit(X, y, epochs=100, verbose=0)
```

- `model.fit(X, y, ...)` trains on the context-target pairs.
- `epochs=100` means the model goes through all pairs 100 times.
- `verbose=0` hides the epoch-by-epoch progress output.
- `history` stores the training loss and metrics from each epoch.

```python
print("Final training loss:", round(history.history["loss"][-1], 4))
```

- `history.history["loss"]` is the list of loss values recorded during training.
- `[-1]` selects the loss from the final epoch.
- `round(..., 4)` rounds it to four decimal places.
- `print(...)` displays the result.

## Step 4: Predict a target word

```python
sample_context = X[0]
```

Selects the first context from the training data.

```python
prediction = model.predict(sample_context.reshape(1, -1), verbose=0)
```

- `.reshape(1, -1)` adds a batch dimension, so the model receives one context example with four word indices.
- `model.predict(...)` returns probability scores for all vocabulary words.
- `verbose=0` hides prediction progress messages.

```python
predicted_word = id_to_word[int(np.argmax(prediction[0]))]
```

- `prediction[0]` selects the score vector for the one example.
- `np.argmax(...)` finds the index with the highest score.
- `int(...)` ensures the index is an integer.
- `id_to_word[...]` converts that index back into a word.

```python
print("Context:", [id_to_word[index] for index in sample_context])
print("Predicted target:", predicted_word)
```

Displays the context words and the model’s predicted target.

## Output interpretation

```text
Final training loss: 2.9258

Context: ['the', 'speed', 'transmission', 'is']
Predicted target: of
```

The model predicts **“of”** from the context `the speed transmission is`. This is the first context-target pair used to train the model, so this output demonstrates a prediction on an example the model has already seen.

The loss is not zero, which means the model still makes prediction errors. Because the corpus is small and the prediction example comes from the training data, this output does not show how well the model predicts unseen text.

### What is CBOW?

**CBOW (Continuous Bag of Words)** is a Word2Vec model used in Natural Language Processing (NLP).

- It takes surrounding words (context words) as input.
- It predicts the missing or target word.
- It learns word relationships using an Embedding layer.

**Example:**

Sentence: The speed of transmission is important.

Context words: The, speed, transmission, is

Target word: of

The CBOW model learns to predict the target word using the surrounding words.

# Step 4: Build and Train the CBOW Model

```python
embedding_size = 16
```

- Defines the size of the word embedding vector.
- Every word is represented using 16 numerical values.

**Why 16?**

It determines how many dimensions are used to represent each word.

### Create the Neural Network

```python
model = Sequential([
    Input(shape=(2 * window_size,)),
    Embedding(input_dim=len(vocabulary), output_dim=embedding_size),
    GlobalAveragePooling1D(),
    Dense(len(vocabulary), activation="softmax")
])
```

Let's understand every layer.

### 1. Sequential()

Creates a neural network in which layers are arranged one after another.

### 2. Input Layer

```python
Input(shape=(2 * window_size,))
```

- Defines the input shape.
- `window_size = 2`.
- `2 * window_size = 4`.

Therefore, the model accepts four context words as input.

### 3. Embedding Layer

```python
Embedding(input_dim=len(vocabulary), output_dim=embedding_size)
```

- `Embedding` – Converts word indexes into numerical vectors.
- `input_dim` – Total number of unique words in vocabulary.
- `output_dim=16` – Each word is represented by 16 numbers.

**Purpose:** Learns numerical representations of words.

### 4. GlobalAveragePooling1D Layer

```python
GlobalAveragePooling1D()
```

- Calculates the average of all context word vectors.
- Combines four word vectors into one average vector.

**Purpose:** Creates a single representation of the context words.

### 5. Dense Layer

```python
Dense(len(vocabulary), activation="softmax")
```

- `Dense` – Fully connected layer.
- `len(vocabulary)` – Number of output neurons, equal to the number of unique words.
- `softmax` – Calculates probabilities for each vocabulary word.

**Purpose:** Predicts the most probable target word.

# 4. Important Viva Questions and Answers

These are likely external viva questions based on this practical.

### Q1. What is CBOW?

CBOW stands for Continuous Bag of Words. It is a Word2Vec model that predicts a target word using its surrounding context words.

### Q2. What is NLP?

NLP stands for Natural Language Processing. It is a branch of AI that helps computers understand and process human language.

### Q3. What is Word2Vec?

Word2Vec is a technique used to convert words into numerical vectors that represent their meaning and relationships.

### Q4. What are the two types of Word2Vec models?

1. CBOW – Predicts the target word using surrounding words.
2. Skip-Gram – Predicts surrounding words using a target word.

### Q5. What is the difference between CBOW and Skip-Gram?

| CBOW | Skip-Gram |
|---|---|
| Predicts the target word. | Predicts surrounding words. |
| Takes context words as input. | Takes the target word as input. |
| Generally faster to train. | Generally slower to train. |

### Q6. What is a context word?

A context word is a word surrounding the target word that helps predict it.

### Q7. What is a target word?

A target word is the word that the CBOW model tries to predict.

### Q8. What is a window size?

Window size determines how many surrounding words are considered for predicting the target word.

In this practical, window size is 2, meaning two words before and two words after.

### Q9. What is tokenization?

Tokenization is the process of dividing text into smaller units called tokens, usually words.

### Q10. What is vocabulary?

Vocabulary is the collection of all unique words present in the text corpus.

### Q11. Why do we convert text into lowercase?

To treat uppercase and lowercase versions of the same word as identical.

For example, `Apple` and `apple` become the same word.

### Q12. Why do we remove punctuation?

To remove unwanted symbols and make text processing easier.

### Q13. What is an Embedding layer?

An Embedding layer converts numerical word indexes into dense numerical vectors.

### Q14. What is embedding size?

Embedding size is the number of dimensions used to represent each word.

In this practical, embedding size is 16.

### Q15. What is GlobalAveragePooling1D?

It calculates the average of the embedding vectors of all context words.

### Q16. Why is the Dense layer used?

The Dense layer performs classification and predicts the target word.

### Q17. What is Softmax?

Softmax is an activation function that converts output values into probabilities.

### Q18. Why is Adam optimizer used?

Adam optimizer updates the model weights to minimize the loss during training.

### Q19. What is an epoch?

One epoch means one complete pass of the entire training dataset through the neural network.

### Q20. What is loss?

Loss measures the difference between the actual output and predicted output.

### Q21. What is sparse categorical cross-entropy?

It is a loss function used for multiclass classification when target labels are represented as integers.

### Q22. What is `np.argmax()`?

It returns the index of the maximum value in an array.

Here, it identifies the word with the highest predicted probability.

### Q23. Why do we use `word_to_id`?

To convert words into numerical indexes.

### Q24. Why do we use `id_to_word`?

To convert numerical indexes back into actual words.

### Q25. What is a corpus?

A corpus is a collection of text documents used for NLP tasks.

### Q26. What is the purpose of `epochs=100`?

It trains the model on the complete training dataset 100 times.

### Q27. What does `verbose=0` mean?

It hides the training or prediction progress from the output.

### Q28. What is the difference between training data X and y?

- X contains input context words.
- y contains the corresponding target words.

### Q29. Why do we use NumPy?

NumPy is used for numerical operations and handling arrays efficiently.

1. Word prediction.
