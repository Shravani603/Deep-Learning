# Chit 8: Sign Language CNN: accuracy and loss graphs

8. Construct a CNN model for Sign Language alphabet recognition. Normalize the image pixels, train the model using the training dataset and display training accuracy, testing accuracy and loss graph. 


# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
from sklearn.preprocessing import LabelEncoder
import matplotlib.pyplot as plt



# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Reshape the images
X_train = X_train.reshape(-1, 28, 28, 1)
X_test = X_test.reshape(-1, 28, 28, 1)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)



# Step 6: Prepare and run the model
history = model.fit(
    X_train, y_train,
    epochs=10,
    batch_size=128,
    validation_split=0.1,
    verbose=0
)



# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
train_accuracy = history.history["accuracy"][-1]
print(f"Training accuracy: {train_accuracy * 100:.2f}%")
print(f"Testing accuracy:  {test_accuracy * 100:.2f}%")


# Step 8: Plot accuracy and loss
plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(history.history["accuracy"], label="Training")
plt.plot(history.history["val_accuracy"], label="Validation")
plt.title("Accuracy")
plt.xlabel("Epoch")
plt.ylabel("Accuracy")
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(history.history["loss"], label="Training")
plt.plot(history.history["val_loss"], label="Validation")
plt.title("Loss")
plt.xlabel("Epoch")
plt.ylabel("Loss")
plt.legend()
plt.tight_layout()
plt.show()






















# Chit 8: Sign Language CNN — Accuracy and Loss Graphs

## Aim

Build a **Convolutional Neural Network (CNN)** to classify Sign Language MNIST images. The code scales the pixel values, trains the model, evaluates it, and plots training and validation accuracy and loss.

## How the CNN processes an image

A CNN can learn from the image’s two-dimensional layout. Convolution layers detect visual patterns, such as edges and shapes. Pooling layers shrink the feature maps, and the final Dense layers use the learned features to select a letter.

```text
28 × 28 image
     ↓
Conv2D → MaxPooling2D → Conv2D → MaxPooling2D
     ↓
Flatten → Dense(128) → Softmax(24 classes)
```

## Step 1: Import the libraries

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
from sklearn.preprocessing import LabelEncoder
import matplotlib.pyplot as plt
```

- `pandas as pd` reads the CSV files.
- `LabelEncoder` converts the class labels into numbers the model can use.
- `Sequential` creates a model made of layers in order.
- `Input` describes the shape of each input image.
- `Conv2D` creates a convolution layer that learns patterns in images.
- `MaxPooling2D` reduces the size of the learned feature maps.
- `Flatten` turns the feature maps into a one-dimensional list.
- `Dense` creates a fully connected layer.
- `matplotlib.pyplot as plt` creates the accuracy and loss graphs.
- `numpy as np` and `tensorflow as tf` are imported but not directly used in this code.

## Step 2: Load and prepare Sign Language MNIST

```python
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")
```

- `pd.read_csv(...)` loads a CSV file as a table.
- `train_df` holds the training data.
- `test_df` holds the test data.
- Each row contains a `label` and the image’s pixel values.

```python
X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
```

These lines prepare the image inputs:

- `X_train` and `X_test` contain the pixels. Here, `X` stands for input data.
- `.drop(columns="label")` removes the answer label, leaving only the pixels.
- `.to_numpy(dtype="float32")` converts the pixel values into a NumPy array of decimal numbers.
- `/ 255.0` scales the pixels from **0–255** to **0–1**. This is called **normalization**.

```python
encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)
```

- `encoder = LabelEncoder()` creates the label converter.
- `fit_transform(...)` learns the label mapping from the training labels and converts them to consecutive numbers.
- `transform(...)` applies the same mapping to the test labels.
- `y_train` and `y_test` contain the correct class numbers for the images. Here, `y` stands for target labels.
- `encoder.classes_` holds the original label values.
- `chr(int(label) + 65)` converts a label number into an uppercase letter. `65` is the character code for `"A"`.
- `class_names` stores the letters in class order. This practical uses its length to find the number of output classes.
- `image_shape` means image height, image width, and number of channels: **28 × 28 × 1**. The variable is defined but not used later.

Sign Language MNIST has **24 classes**. The gestures for J and Z are omitted because they involve movement.

## Step 3: Reshape the images

```python
X_train = X_train.reshape(-1, 28, 28, 1)
X_test = X_test.reshape(-1, 28, 28, 1)
```

A CNN expects each image to have a height, width, and channel dimension.

- `28, 28` means each image is 28 pixels high and 28 pixels wide.
- `1` means it is a grayscale image with one channel.
- `-1` tells Python to work out the number of images automatically.

The resulting shape for each set is:

```text
(number of images, 28, 28, 1)
```

## Step 4: Build the model

```python
num_classes = len(class_names)
```

- `len(class_names)` counts the classes.
- `num_classes` is **24** for this dataset.

```python
model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

`Sequential([...])` places each layer in order.

| Layer | What it does |
|---|---|
| `Input(shape=X_train.shape[1:])` | Sets the image shape to `(28, 28, 1)`. The first dimension is skipped because it represents the number of images. |
| `Conv2D(32, (3, 3), ...)` | Learns 32 image filters. Each filter looks at a 3 × 3 region at a time. |
| `MaxPooling2D((2, 2))` | Shrinks each feature map by selecting the largest value in each 2 × 2 region. |
| `Conv2D(64, (3, 3), ...)` | Learns 64 more filters to detect more complex patterns. |
| `MaxPooling2D((2, 2))` | Shrinks the feature maps again. |
| `Flatten()` | Converts the feature maps into a one-dimensional list for the Dense layers. |
| `Dense(128, ...)` | Uses 128 neurons to combine the learned image features. |
| `Dense(num_classes, ...)` | Produces 24 output scores, one for each gesture class. |

- `activation="relu"` applies ReLU: negative values become zero, while positive values remain.
- `activation="softmax"` converts the final scores into probabilities that add up to about 1. The largest probability is the model’s predicted class.

Assuming the default `valid` padding, the feature-map sizes are:

```text
28 × 28 × 1
→ 26 × 26 × 32
→ 13 × 13 × 32
→ 11 × 11 × 64
→ 5 × 5 × 64
→ 1,600 values after Flatten
```

The flattened size is `5 × 5 × 64 = 1,600`.

## Step 5: Compile the model

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

This sets how the model learns and how its performance is measured:

- `optimizer="adam"` chooses Adam, which updates the model’s weights during training.
- `loss="sparse_categorical_crossentropy"` measures how far the predicted class probabilities are from the correct integer labels.
- `metrics=["accuracy"]` asks Keras to record the fraction of predictions that are correct.

“Sparse” fits this code because the class labels are integers rather than one-hot vectors.

## Step 6: Train the model

```python
history = model.fit(
    X_train, y_train,
    epochs=10,
    batch_size=128,
    validation_split=0.1,
    verbose=0
)
```

- `model.fit(...)` trains the model.
- `X_train` provides the images; `y_train` provides the correct labels.
- `epochs=10` means the model goes through the training data 10 times.
- `batch_size=128` means it processes up to 128 images before updating its weights.
- `validation_split=0.1` reserves 10% of the training data to check performance during training. Those examples are used for validation, not for weight updates.
- `verbose=0` hides the training progress messages.
- `history` stores the accuracy and loss values recorded at each epoch. The graph uses these values.

## Step 7: Evaluate on test data

```python
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
```

- `model.evaluate(...)` measures performance on the separate test data.
- It returns the test loss and test accuracy, in that order.
- `_` receives the loss, which this line does not use.
- `test_accuracy` receives the accuracy.
- `verbose=0` hides the evaluation progress messages.

```python
train_accuracy = history.history["accuracy"][-1]
```

- `history.history` is a dictionary containing the recorded training results.
- `"accuracy"` selects the training accuracy values.
- `[-1]` selects the last recorded value, from epoch 10.

```python
print(f"Training accuracy: {train_accuracy * 100:.2f}%")
print(f"Testing accuracy:  {test_accuracy * 100:.2f}%")
```

- `print(...)` displays the results.
- `* 100` converts an accuracy fraction into a percentage.
- `:.2f` displays two digits after the decimal point.
- The exact printed percentages are not visible in the attached graph; it shows the curves instead.

# 4. External Viva Questions and Answers

### Basic CNN Questions

**Q1. What is CNN?**  
CNN stands for Convolutional Neural Network. It is a deep learning algorithm mainly used for image recognition and classification.

**Q2. Why do we use CNN for Sign Language recognition?**  
Because CNN can automatically extract important features such as hand shape, edges and patterns from images.

**Q3. What is the difference between ANN and CNN?**  
- ANN uses fully connected layers.
- CNN uses convolution and pooling layers to extract image features.
- CNN is generally more suitable for image recognition.

**Q4. What is a convolution layer?**  
It extracts important features from an image using filters.

**Q5. What is a filter in CNN?**  
A filter is a small matrix that moves over an image to detect features such as edges and patterns.

**Q6. What is pooling?**  
Pooling reduces the dimensions of feature maps while retaining important information.

**Q7. What is Max Pooling?**  
Max Pooling selects the maximum value from a particular region, such as a 2 × 2 region.

**Q8. What is the purpose of the Flatten layer?**  
It converts 2D feature maps into a 1D vector.

**Q9. What is a Dense layer?**  
A Dense layer is a fully connected layer in which every neuron is connected to all neurons in the previous layer.

**Q10. What is ReLU?**  
ReLU stands for Rectified Linear Unit. It converts negative values into zero and keeps positive values unchanged.

**Q11. What is Softmax?**  
Softmax converts output values into probabilities for different classes. The class with the highest probability is selected.

### Dataset and Preprocessing Questions

**Q12. Which dataset is used in this practical?**  
Sign Language MNIST dataset.

**Q13. What is the size of each image?**  
28 × 28 pixels.

**Q14. Is the dataset grayscale or RGB?**  
It is grayscale.

**Q15. Why do we divide pixel values by 255?**  
To normalize pixel values from the range 0–255 to 0–1.

**Q16. Why do we reshape the images?**  
CNN requires image data in height, width and channel format.

**Q17. Why is the channel value 1?**  
Because the images are grayscale and have only one channel.

**Q18. How many classes are present in Sign Language MNIST?**  
There are 24 classes because J and Z are excluded.

**Q19. Why are J and Z excluded?**  
Their sign language gestures require movement, so they cannot be represented properly using a single static image.

**Q20. What is Label Encoding?**  
It converts categorical labels into numerical values.

### Training and Evaluation Questions

**Q21. What is an epoch?**  
One complete pass through the entire training dataset.

**Q22. What is batch size?**  
The number of samples processed before updating model weights.

**Q23. What is an optimizer?**  
An optimizer updates the model's weights to reduce loss.

**Q24. Which optimizer is used in this practical?**  
Adam optimizer.

**Q25. What is a loss function?**  
It measures the difference between actual and predicted outputs.

**Q26. Which loss function is used here?**  
Sparse categorical crossentropy.

**Q27. Why do we use sparse categorical crossentropy?**  
Because we have multiple classes and the target labels are provided as integers.

**Q28. What is training accuracy?**  
The percentage of correct predictions on training data.

**Q29. What is testing accuracy?**  
The percentage of correct predictions on unseen testing data.

**Q30. What is validation data?**  
Data used during training to check how well the model performs on unseen samples.

**Q31. What does `validation_split=0.1` mean?**  
It reserves 10% of the training data for validation.

**Q32. What is overfitting?**  
Overfitting occurs when a model performs very well on training data but poorly on unseen data.

**Q33. How can we reduce overfitting?**  
By using dropout, data augmentation, regularization, early stopping or more training data.

To understand how the model's performance changes during training.

It shows training and validation loss across epochs.

Generally, accuracy should increase.

**Q38. What should happen to loss during training?**  
Generally, loss should decrease.

**Q39. What does increasing training accuracy but decreasing validation accuracy indicate?**  
It may indicate overfitting.

It stores training and validation metrics, such as accuracy and loss, for every epoch.
