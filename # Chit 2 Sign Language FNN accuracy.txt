# Chit 2: Sign Language FNN: accuracy and loss graphs

2. Construct a Feedforward Neural Network for Sign Language alphabet recognition. Train the model using the training dataset and evaluate it using the testing dataset. Display the training accuracy, testing accuracy and loss graph. 


# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
import pandas as pd
from sklearn.preprocessing import LabelEncoder
import matplotlib.pyplot as plt

# Step 2: Load and prepare Sign Language MNIST
train_df = pd.read_csv("sign_mnist_train.csv")
test_df = pd.read_csv("sign_mnist_test.csv")

X_train = train_df.drop(columns="label").to_numpy(dtype="float32") / 255.0
X_test = test_df.drop(columns="label").to_numpy(dtype="float32") / 255.0

encoder = LabelEncoder()
y_train = encoder.fit_transform(train_df["label"])
y_test = encoder.transform(test_df["label"])
class_names = [chr(int(label) + 65) for label in encoder.classes_]
image_shape = (28, 28, 1)


# Step 3: Flatten the images
X_train = X_train.reshape(-1, 28, 28).reshape(-1, 784)
X_test = X_test.reshape(-1, 28, 28).reshape(-1, 784)


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
history = model.fit(
    X_train, y_train,
    epochs=15,
    batch_size=128,
    validation_split=0.1,
    verbose=0
)


# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
train_accuracy = history.history["accuracy"][-1]
print(f"Training accuracy: {train_accuracy * 100:.2f}%")
print(f"Testing accuracy:  {test_accuracy * 100:.2f}%")


# Step 8: Plot accuracy and loss
plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(history.history["accuracy"], label="Training")
plt.plot(history.history["val_accuracy"], label="Validation")
plt.title("Accuracy")
plt.xlabel("Epoch")
plt.ylabel("Accuracy")
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(history.history["loss"], label="Training")
plt.plot(history.history["val_loss"], label="Validation")
plt.title("Loss")
plt.xlabel("Epoch")
plt.ylabel("Loss")
plt.legend()
plt.tight_layout()
plt.show()

**Why do we flatten images?**

Because Dense layers in our Feedforward Neural Network expect one-dimensional feature vectors.

The model passes through the training dataset 15 times.

One epoch means one complete pass through the training dataset.

### 4. `batch_size=128`

The model processes 128 images together before updating its weights.

### 5. `validation_split=0.1`

**This is an important new parameter.**

It means 10% of the training data is separated for validation.

For example:

Suppose we have 1,000 training images.

- 90% = 900 images used for training.
- 10% = 100 images used for validation.

### What is Validation Data?

Validation data is used to check how well the model performs during training.

It helps us monitor the model's performance on data that is not used for updating weights.

**Difference between Training, Validation and Testing:**

| Data | Purpose |
|---|---|
| Training Data | Used to teach the model. |
| Validation Data | Used to monitor performance during training. |
| Testing Data | Used to evaluate the final trained model. |

### 6. `verbose=0`

Controls the display of training progress.

- 0 = No progress display.
- 1 = Progress bar.
- 2 = One line per epoch.

### What happens during training?

1. Training images are given to the model.
2. The model predicts the output.
3. Predicted output is compared with actual output.
4. Loss is calculated.
5. Adam optimizer updates the weights.
6. Validation accuracy and validation loss are calculated.

This is a very important line.

These lines display the training and testing accuracy.
