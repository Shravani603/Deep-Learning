# Chit 17: Handwritten MNIST CNN: digit classification

17. Develop a CNN model using TensorFlow/Keras to recognize handwritten digits. Apply convolution and max-pooling operations, train the model and display testing accuracy. Use Dataset - Handwritten MNIST 

# Step 1: Import the libraries
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten


# Step 2: Load and prepare Handwritten MNIST
from tensorflow.keras.datasets import mnist

(X_train, y_train), (X_test, y_test) = mnist.load_data()
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
class_names = [str(i) for i in range(10)]
image_shape = (28, 28, 1)


# Step 3: Reshape the images
X_train = X_train[..., np.newaxis]
X_test = X_test[..., np.newaxis]


# Step 4: Build the model
num_classes = len(class_names)
model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])


# Step 5: Compile and train
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)


# Step 6: Prepare and run the model
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)


# Step 7: Evaluate on test data
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")























# Chit 17: Handwritten MNIST CNN — Digit Classification

## Aim

Build a Convolutional Neural Network (CNN) to recognize handwritten digits from 0 to 9. The model uses convolution and max-pooling layers, then reports its accuracy on test images.

## How the model works

```text
28 × 28 digit image → Conv2D → MaxPooling2D → Conv2D → MaxPooling2D
                   → Flatten → Dense(128) → Softmax(10 digits)
```

Convolution layers learn visual features from the image. Pooling layers reduce the feature map size. Dense layers then use those features to predict the digit.

## Step 1: Import the libraries

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Input, Dense
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten
```

- `numpy as np` imports NumPy. It is used later for `np.newaxis`.
- `tensorflow as tf` imports TensorFlow, but `tf` is not directly used later.
- `Sequential` creates a model whose layers run in order.
- `Input` defines the shape of each input image.
- `Dense` creates fully connected layers.
- `Conv2D` creates a convolution layer for learning image patterns.
- `MaxPooling2D` reduces the size of feature maps.
- `Flatten` turns feature maps into a one-dimensional list.

## Step 2: Load and prepare Handwritten MNIST

```python
from tensorflow.keras.datasets import mnist

(X_train, y_train), (X_test, y_test) = mnist.load_data()
```

- `mnist` is the handwritten-digit dataset provided by Keras.
- `load_data()` loads the images and their correct labels.
- `X_train`, `y_train` hold the training images and digit labels.
- `X_test`, `y_test` hold separate test images and their labels.

```python
X_train = X_train.astype("float32") / 255.0
X_test = X_test.astype("float32") / 255.0
```

- `.astype("float32")` converts pixels to decimal numbers.
- `/ 255.0` scales pixels from 0–255 to 0–1. This is called **normalization**.

```python
class_names = [str(i) for i in range(10)]
image_shape = (28, 28, 1)
```

- `range(10)` generates the numbers 0 through 9.
- `str(i)` converts each number into text.
- `class_names` becomes `["0", "1", ..., "9"]`. It is not used later in this code.
- `image_shape` describes a 28 × 28 grayscale image with one channel. It is also not used later.

## Step 3: Reshape the images

```python
X_train = X_train[..., np.newaxis]
X_test = X_test[..., np.newaxis]
```

The original images have shape:

```text
(number of images, 28, 28)
```

A CNN expects an additional channel dimension. These lines add it, making the shape:

```text
(number of images, 28, 28, 1)
```

- `...` means keep all existing dimensions.
- `np.newaxis` adds a new dimension at the end.
- `1` represents the one grayscale channel.

## Step 4: Build the model

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

- `num_classes` counts the digit classes: 10.
- `Sequential([...])` arranges the model layers in order.
- `Input(shape=X_train.shape[1:])` sets the input shape to `(28, 28, 1)`. It excludes the number-of-images dimension.
- `Conv2D(32, (3, 3), ...)` learns 32 filters, each looking at a 3 × 3 image region.
- `MaxPooling2D((2, 2))` reduces each feature map by selecting the largest value in each 2 × 2 region.
- The second `Conv2D` learns 64 filters to detect more complex patterns.
- The second pooling layer reduces the feature maps again.
- `Flatten()` converts the feature maps into a one-dimensional list.
- `Dense(128, ...)` combines the learned features using 128 neurons.
- `Dense(num_classes, ...)` creates 10 output neurons, one for each digit.
- `activation="relu"` changes negative values to zero and keeps positive values.
- `activation="softmax"` converts output scores into probabilities. The largest probability corresponds to the predicted digit.

With the default valid padding, the layer sizes are approximately:

```text
28 × 28 × 1
→ 26 × 26 × 32
→ 13 × 13 × 32
→ 11 × 11 × 64
→ 5 × 5 × 64
→ 1,600 values after Flatten
```

## Step 5: Compile the model

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)
```

- `optimizer="adam"` selects how the model updates its weights during training.
- `loss="sparse_categorical_crossentropy"` measures how different the predictions are from the correct integer labels.
- `metrics=["accuracy"]` asks Keras to track the fraction of correct predictions.

“Sparse” fits because the digit labels are integers, such as `7`, rather than one-hot vectors.

## Step 6: Train the model

```python
model.fit(X_train, y_train, epochs=10, batch_size=128, verbose=0)
```

- `model.fit(...)` trains the model using the training images and labels.
- `epochs=10` means it processes the full training set 10 times.
- `batch_size=128` means it processes up to 128 images before updating its weights.
- `verbose=0` hides the training progress messages.

## Step 7: Evaluate on test data

```python
_, test_accuracy = model.evaluate(X_test, y_test, verbose=0)
```

- `model.evaluate(...)` measures performance on the test images.
- It returns loss first and accuracy second.
- `_` receives the loss, which this line does not use.
- `test_accuracy` receives the accuracy.
- `verbose=0` hides progress messages.

```python
print(f"Testing accuracy: {test_accuracy * 100:.2f}%")
```

- `print(...)` displays the result.
- `test_accuracy * 100` converts the fraction to a percentage.
- `:.2f` formats it to two decimal places.

## Output interpretation

```text
Testing accuracy: 98.99%
```

The CNN correctly classified **98.99% of the test images**.

(60000, 28, 28, 1)

### Step 4: Build the CNN Model

```python
num_classes = len(class_names)

model = Sequential([
    Input(shape=X_train.shape[1:]),
    Conv2D(32, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(num_classes, activation="softmax")
])
```

This is the most important part of the practical.

Let's understand each layer.

**1. Number of classes**

```python
num_classes = len(class_names)
```

- Calculates the number of output classes.
- Since there are digits from 0 to 9, `num_classes = 10`.

**2. Sequential model**

```python
model = Sequential([...])
```

Creates a CNN in which layers are arranged one after another.

**3. Input layer**

```python
Input(shape=X_train.shape[1:])
```

- Defines the input shape of each image.
- `X_train.shape[1:]` gives `(28, 28, 1)`.
- Therefore, the model accepts 28 × 28 grayscale images.

**4. First Convolutional Layer**

```python
Conv2D(32, (3, 3), activation="relu")
```

- `Conv2D` performs a convolution operation.
- `32` represents the number of filters.
- `(3,3)` represents the size of each filter.
- `activation="relu"` applies the ReLU activation function.

**What is convolution?**

Convolution is an operation in which small filters (kernels) slide over an image to identify important features.

For example, convolution can help identify:
- Edges.
- Curves.
- Lines.
- Shapes.
- Patterns in handwritten digits.

**What is a filter?**

A filter is a small matrix that moves over an image to extract specific features.

Here, the first convolutional layer uses 32 filters of size 3 × 3.

**5. First Max-Pooling Layer**

```python
MaxPooling2D((2, 2))
```

- Performs max-pooling operation.
- Uses a 2 × 2 pooling window.
- Selects the maximum value from each 2 × 2 region.
- Reduces the spatial dimensions of the feature maps.

**What is Max-Pooling?**

Max-pooling is a downsampling operation that selects the maximum value from a small region of a feature map.

**Why do we use Max-Pooling?**

1. Reduces image feature dimensions.
2. Reduces computational requirements.
3. Retains important features.
4. Helps reduce sensitivity to small changes in image position.

**6. Second Convolutional Layer**

```python
Conv2D(64, (3, 3), activation="relu")
```

- Uses 64 filters.
- Each filter has a size of 3 × 3.
- Extracts more complex features from the previous feature maps.
- Uses ReLU activation.

**7. Second Max-Pooling Layer**

```python
MaxPooling2D((2, 2))
```

- Again uses a 2 × 2 pooling window.
- Reduces the feature map dimensions further.
- Retains the maximum values from each region.

**8. Flatten Layer**

```python
Flatten()
```

- Converts the multidimensional feature maps into a one-dimensional array.
- Makes the data suitable for the Dense layers.

**Why do we use Flatten?**

Convolution and pooling layers produce multidimensional feature maps, whereas Dense layers require one-dimensional input.

**9. Dense Hidden Layer**

```python
Dense(128, activation="relu")
```

- Contains 128 neurons.
- Uses ReLU activation.
- Learns patterns from the features extracted by convolutional layers.

**10. Output Layer**

```python
Dense(num_classes, activation="softmax")
```

- Contains 10 neurons.
- Each neuron represents one digit from 0 to 9.
- Softmax produces probabilities for each digit.
- The digit with the highest probability is selected.

### CNN Architecture Diagram

```text
          Input Image
        28 × 28 × 1
              |
              ↓
     Convolutional Layer 1
       32 Filters (3 × 3)
         ReLU Activation
              |
              ↓
       Max-Pooling Layer
           (2 × 2)
              |
              ↓
     Convolutional Layer 2
       64 Filters (3 × 3)
         ReLU Activation
              |
              ↓
       Max-Pooling Layer
           (2 × 2)
              |
              ↓
         Flatten Layer
              |
              ↓
        Dense Layer

         ReLU Activation
              |
              ↓
        Output Layer
         10 Neurons
       Softmax Activation
              |
              ↓

```

### Understanding the Dimensions After Each Layer

This is useful for viva questions.

| Layer | Output shape (excluding batch size) |
|---|---|
| Input | 28 × 28 × 1 |
| Conv2D (32 filters) | 26 × 26 × 32 |
| MaxPooling2D | 13 × 13 × 32 |
| Conv2D (64 filters) | 11 × 11 × 64 |
| MaxPooling2D | 5 × 5 × 64 |
| Flatten | 1600 |
| Dense | 128 |
| Output | 10 |

**How are these dimensions calculated?**

- First convolution: 28 − 3 + 1 = 26.
- First pooling: 26 ÷ 2 = 13.
- Second convolution: 13 − 3 + 1 = 11.
- Second pooling: 11 × 11 becomes 5 × 5 using a 2 × 2 window with the default stride of 2.
- Flatten: 5 × 5 × 64 = 1600.

Note: The convolution layers use valid padding by default, which means no extra padding is added around the image.
